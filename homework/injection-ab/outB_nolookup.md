# visual-check 실행 컨텍스트 — 주입 없음 + 파일 조회 금지 조건 답변 (Q1~Q6)

> 조건: 컨텍스트 주입 없음, 파일 조회 금지(도구 사용 0회). 실행자가 이미 아는 지식만으로 답함.

## Q1. AI 판정 결과 파일 경로 + JSON 스키마
모름. 판정 결과를 어떤 파일에 쓰는지, 키 구조가 무엇인지 정확히 모릅니다. 추측하지 않겠습니다.

## Q2. stage 설정 파일명 + 핵심 키 2개
모름. 설정 파일명과 핵심 키 2개를 모릅니다. `stage.json` 같은 이름이 떠오르지만 근거 없는 추측이라 제시하지 않겠습니다.

## Q3. 촬영 스크립트가 보는 DOM 속성 + 컴포넌트 루트 위치
모름. `data-variant` 같은 패턴이 흔하긴 하나 이 프로젝트의 실제 속성/루트 위치는 단정할 수 없습니다.

## Q4. lens.json overall 계산식
부분만 앎. 세 렌즈(레이아웃·색대비·타이포)가 있다는 것까지는 알지만, overall을 어떻게 합치는지(최악값/평균/가중치)는 모릅니다. "가장 나쁜 렌즈를 따른다"가 그럴듯하나 추측이라 확정하지 않겠습니다.

## Q5. "블라인드(blind)" 원칙
개념 방향만 앎. 판정 에이전트에게 다른 판정 결과나 앞선 회차 판정(아마 기대값 힌트)을 넘기지 않아 독립적으로 보게 하는 것으로 이해하나, "정확히 무엇 무엇을 안 넘기는지"의 완전한 목록은 확인 없이 단정 못 합니다.

## Q6. dev 서버 소유권 규칙
모름. "이미 떠 있으면 재사용, 내가 띄웠으면 정리"가 흔한 규약이지만 이 프로젝트의 실제 규칙 문구는 모릅니다.

확인: 이 답변을 작성하며 어떤 파일도 읽지 않았고 어떤 조회 도구도 사용하지 않았습니다(tool_uses: 0).
