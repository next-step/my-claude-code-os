# 요청: 도서 연체료 계산

연체 일수와 도서 정보를 받아 연체료를 계산하는 기능을 만들어 주세요.

- 연체료는 하루당 500원입니다.
- 다만 일주일(7일) 연체한 경우 총 연체료는 3,000원입니다.
- 연체료는 해당 도서 정가를 초과할 수 없습니다.
- 인기 도서(예약자가 있는 도서)는 연체료가 2배입니다.
- 어떤 경우에도 연체료가 10,000원을 넘으면 초과분은 면제하고, 정가가 10,000원보다 낮아도 최소한 하루당 500원 기준의 연체료는 전액 부과합니다.
- 연체 30일이 지나면 분실 처리되어 연체료 대신 정가를 배상합니다. 분실 처리 후에도 연체료는 계속 하루당 500원씩 누적됩니다.
