## 요약

연체 일수와 도서 정보(정가, 인기 도서 여부)를 입력받아 연체료를 계산하는 기능이다. 기본 요금은 하루당 500원이며 7일 이상 연체 시 주간 할인 구간이 적용되고, 인기 도서는 2배 할증이 붙는다. 최종 청구액은 도서 정가와 10,000원 상한의 영향을 받고, 30일을 초과해 연체되면 연체료 청구 대신 정가 배상으로 전환된다. 다만 request.md 자체에 상호 모순되는 조항이 여럿 있어(정가 상한 vs 기본 연체료 전액 보장, 분실 후 연체료 청구 대체 vs 연체료 계속 누적 등) 이 문서에서 해석 기본값을 확정한다 — 확정되지 않은 사항은 아래 "정책 충돌"에 `(기본값)`으로 표기했다.

## 정책 충돌

기존 코드/문서: 없음 (그린필드 프로젝트, `src/`·`tests/`·기존 spec 없음).

request.md 내부 모순/해석 갈림 지점은 다음과 같다. 각 항목에 선택지와 기본값을 명시한다.

1. **"7일 연체 시 3,000원" 조항의 적용 범위** — 하루당 500원이면 7일은 3,500원인데 조항은 3,000원이라 명시한다. 두 가지 해석 가능:
   - (a) 연체일수가 정확히 7일인 경우에만 3,000원 특가 적용, 8일 이상은 규정 없음(공백).
   - (b) 연체 7일째부터는 "1~7일 3,000원 정액 + 8일째부터 하루 500원 가산"의 주간 할인 구간으로 해석.
   - **(기본값) (b)를 채택한다.** 8일 이상 구간에 대한 명시적 규정이 없는 (a)는 계산 불능 상태를 만들어 기능이 성립하지 않으므로, 연속적으로 계산 가능한 (b)를 기본값으로 정한다. → P-001-2에 반영.

2. **"연체료는 정가를 초과할 수 없음"(이하 정가 상한)과 "정가가 10,000원보다 낮아도 하루당 500원 기준 연체료는 전액 부과"(이하 기본 연체료 보장)의 충돌** — 정가가 기본 연체료보다 낮은 책의 경우 두 조항이 동시에 성립할 수 없다(예: 정가 2,000원, 연체 3일 → 기본 연체료 1,500원인데 정가 상한 적용 시 2,000원 그대로라 문제 없지만, 정가 1,000원이면 정가 상한은 1,000원, 기본 연체료 보장은 1,500원 전액 부과라 모순). 두 해석:
   - (a) 정가 상한이 항상 우선 — 어떤 경우에도 정가를 넘지 못한다. 이 경우 "기본 연체료는 전액 부과" 문구는 무의미해진다.
   - (b) 기본 연체료(할증 전, P-001-1/2 계산값)는 정가 상한의 영향을 받지 않는 하한선이고, 정가 상한은 인기 도서 할증분(P-001-3)에만 적용된다. 즉 `연체료 = min(할증적용액, max(정가, 기본연체료))`.
   - **(기본값) (b)를 채택한다.** request.md가 "정가가 낮아도 최소한 기본 연체료는 전액 부과"라고 명시적으로 예외를 서술했으므로, 이 문구를 무의미하게 만드는 (a)보다 문구를 실제로 반영하는 (b)가 요구를 더 충실히 구현한다. → P-001-4에 반영.

3. **10,000원 상한("어떤 경우에도 초과분 면제")과 "분실 처리 후에도 연체료는 계속 하루당 500원씩 누적"의 충돌** — "어떤 경우에도"는 상한이 예외 없이 적용됨을 시사하지만, 분실 후 연체료가 "계속 누적"된다는 조항은 상한이 없을 때만 의미가 있다(상한이 걸리면 값이 10,000원에 고정되어 "누적"이라 부를 이유가 없다). 두 해석:
   - (a) 10,000원 상한이 분실 후 누적치에도 그대로 적용되어 값이 10,000원에서 멈춘다.
   - (b) 실제 청구액(분실 후에는 정가 배상액)과 별개로, "누적 연체료"는 참고용 수치로 상한·할인·정가상한 없이 하루 500원씩 무한 누적된다.
   - **(기본값) (b)를 채택한다.** "계속 누적"이라는 표현을 문자 그대로 살리려면 상한 미적용이 되어야 하며, 실제 청구액은 어차피 정가 배상으로 대체되어 이 누적치가 청구에 영향을 주지 않으므로 안전하다. → P-001-7에 반영.

4. **"연체 30일이 지나면" 분실 처리의 경계값** — 연체일수가 정확히 30일인 경우 분실 처리 대상인지 불명확. 두 해석:
   - (a) 30일 포함(연체일수 >= 30일부터 분실).
   - (b) 30일 초과만 해당(연체일수 > 30, 즉 31일째부터 분실).
   - **(기본값) (b)를 채택한다.** "지나면(경과하면)"이라는 한국어 표현은 통상 해당 기준일을 완전히 넘어선 시점을 가리키므로 30일 당일은 아직 연체료 계산 대상으로 본다. → P-001-6에 반영.

## 정책

### P-001-1: 기본 연체료(7일 미만)
- 규칙: 연체일수가 7일 미만이면 연체료는 연체일수 × 500원이다.
- 예시: 연체 3일 → 3 × 500 = 1,500원

### P-001-2: 주간 할인 구간(7일 이상) (기본값)
- 규칙: 연체일수가 7일 이상이면 기본 연체료는 3,000원 + (연체일수 − 7) × 500원이다.
- 예시: 연체 10일 → 3,000 + (10 − 7) × 500 = 4,500원 (연체 7일 정확히는 3,000 + 0 = 3,000원)

### P-001-3: 인기 도서 2배 할증
- 규칙: 예약자가 있는 인기 도서는 P-001-1/P-001-2로 계산된 기본 연체료를 2배로 한다. 인기 도서 여부는 연체료 계산 함수 호출 시점에 입력으로 주어지는 값을 그대로 사용하며, 대출 기간 중 예약 상태 변화 이력은 조회하지 않는다(스냅샷 없음, spec-review에서 명확화).
- 예시: 인기 도서, 연체 3일(기본 연체료 1,500원) → 1,500 × 2 = 3,000원

### P-001-4: 정가 상한과 기본 연체료 하한 (기본값, spec-review에서 우선순위 명시)
- 규칙: 연체료는 다음 순서로 결정된다 — ① 할증적용액(P-001-3)을 정가로 상한한다: `min(할증적용액, 정가)`. ② 그 결과가 P-001-1/P-001-2의 기본 연체료보다 낮으면 기본 연체료까지 끌어올린다(하한 보장). 즉 `연체료 = max(min(할증적용액, 정가), 기본연체료)`. (이 식은 spec 초안의 `min(할증적용액, max(정가, 기본연체료))`와 대수적으로 동치다.)
- 예시: 정가 2,000원, 인기 도서, 연체 3일 → 기본 연체료 1,500원, 할증액 3,000원, `min(3000,2000)=2000`, `max(2000,1500)=2,000원`. 비인기 도서(할증 없음, 1,500원)라면 `min(1500,2000)=1500`, `max(1500,1500)=1,500원`으로 정가와 무관하게 그대로 부과된다.
- 예시(하한이 할증보다 우선하는 경계 사례): 정가 1,000원, 인기 도서, 연체 3일 → 기본 연체료 1,500원, 할증액 3,000원, `min(3000,1000)=1000`, `max(1000,1500)=1,500원`. **정가가 기본 연체료보다 낮은 책은 인기 여부와 무관하게 기본 연체료만 부과되고 2배 할증이 최종 금액에 반영되지 않는다** — "정가가 낮아도 기본 연체료는 전액 부과"라는 하한 보장이 할증보다 우선하기 때문에 생기는 의도된 결과다. (spec-review 검토에서 이 경계 사례가 P-001-3의 취지를 약화시킨다는 지적이 있었으나, 할증배수를 하한에도 곱하는 대안은 대수적으로 `min(할증적용액, max(정가,기본연체료×배수))`가 항상 `할증적용액`과 같아져 정가 상한 자체를 완전히 무력화하므로 채택하지 않았다. 대신 이 경계 동작을 예시로 명문화해 놀라움 없는 결정론적 규칙으로 확정한다.)

### P-001-5: 10,000원 절대 상한
- 규칙: P-001-1~4를 거쳐 산출된 실제 청구 연체료는 10,000원을 초과하지 않는다.
- 예시: 정가 50,000원, 인기 도서, 연체 20일 → 기본 연체료 3,000 + 13×500 = 9,500원, 할증액 19,000원, 정가상한 `max(50000,9500)=50000`이므로 `min(19000,50000)=19,000원` → 10,000원 상한 적용 후 최종 10,000원

### P-001-6: 30일 초과 분실 처리 (기본값, spec-review에서 단조성 보정 추가)
- 규칙: 연체일수가 30일을 초과하면(31일째부터) 분실 처리되며, 실제 청구액은 `max(정가, 연체 30일째 기준으로 P-001-1~5를 적용했을 때의 연체료)`다. (연체가 길어졌다는 이유로 청구액이 30일째보다 줄어드는 역전을 막는 하한이다.)
- 예시: 정가 8,000원, 비인기 도서, 연체 31일 → 30일째 기준 연체료 = 3,000+23×500=14,500원 → P-001-5(10,000원 상한) 적용 후 10,000원. `max(8000, 10000) = 10,000원`이 청구액이다. (단순히 정가 8,000원만 청구하면 30일째의 10,000원보다 줄어들어 "더 연체할수록 청구액이 감소"하는 모순이 생기므로 보정했다 — spec-review 지적 반영.) 연체 30일(경계값)이면 아직 분실 아님, P-001-1~5 계산이 그대로 적용된다.

### P-001-7: 분실 후 연체료 참고 누적치 (기본값)
- 규칙: 분실 처리된 이후에도 "연체료" 값은 실제 청구액(정가 배상 및 P-001-6의 단조성 보정 하한)과 별개로, 할인·할증·상한 없이 연체일수 × 500원으로 계속 누적되는 참고용 수치로 함께 제공된다.
- 예시: 정가 8,000원, 연체 35일 → 청구액 = max(8000, 10000) = 10,000원(P-001-6), 참고 누적 연체료 = 35 × 500 = 17,500원

### P-001-8: 입력 유효성 (기본값, spec-review에서 추가)
- 규칙: 연체일수는 0 이상의 정수만 유효 입력이며, 음수이거나 정수가 아닌 값이 입력되면 오류(예외)를 발생시킨다.
- 예시: 연체일수 = -1 → 오류(예외) 발생. 연체일수 = 0 → 정상 처리되어 연체료 0원(P-001-1: 0 × 500 = 0).
