# 요청: 배송비 계산 함수

주문 정보를 받아 배송비를 계산하는 함수 `calculate_shipping(order)` 를 만들어 주세요.

`order`는 dict이며 키는 `subtotal`(상품 합계 금액, 정수 원), `region`(문자열: "일반", "제주", "도서산간"), `is_express`(bool, 특급 배송 여부)입니다.

규칙은 다음과 같습니다:

1. 기본 배송비는 3,000원이다.
2. `subtotal`이 50,000원 이상이면 기본 배송비는 0원이다 (무료 배송).
3. `region`이 "제주"면 3,000원, "도서산간"이면 5,000원의 지역 추가비가 붙는다. 지역 추가비는 무료 배송 여부와 무관하게 항상 부과된다.
4. `is_express`가 true면 특급비 2,000원이 추가된다. 특급비도 무료 배송 여부와 무관하게 항상 부과된다.
5. `subtotal`이 0 이하이거나 `region`이 위 세 값이 아니면 `ValueError`를 발생시킨다.

예: subtotal=30,000, region="제주", is_express=true → 3,000(기본) + 3,000(제주) + 2,000(특급) = 8,000원.
예: subtotal=60,000, region="도서산간", is_express=false → 0(무료) + 5,000 = 5,000원.
