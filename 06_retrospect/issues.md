# 이슈 로그 (Issues)

> 메타 루프 ⑤의 **미해결 부채 목록.** 회고 중 발견했지만 그 자리에서 못 고친 문제를 여기 쌓는다.
> 각 이슈는 상태(`열림`/`해결`)를 가진다. SessionStart 훅이 매 세션 시작에 **`열림`만** 골라 주입하므로,
> 열린 이슈는 계속 눈에 밟히고 → 하나씩 닫히며 → OS가 수렴한다(부채 감소).
> 새 이슈는 맨 위에 추가(최신순). 닫을 땐 파일을 옮기지 말고 그 자리에서 `상태: 해결 (날짜)`로 갱신.
> `/retrospect`가 세션 끝에 append/갱신한다.

---

## 기록 템플릿 (복붙해서 사용)

```
### [YYYY-MM-DD] #NNN 제목  · 상태: 열림
- 증상: (무엇이 잘못됐거나 불편했나 — 구체적으로)
- 원인 추정: (아는 만큼만. 모르면 "미상"으로 두고 추정 금지)
- 개선 액션: (무엇을 하면 이 이슈가 닫히나)
- 해결 메모: (닫을 때 채움 — 날짜 + 실제로 한 조치)
```

번호 규칙: `#NNN`은 단순 증가(001, 002, ...). 해결 시 `· 상태: 열림` → `· 상태: 해결 (YYYY-MM-DD)`.
