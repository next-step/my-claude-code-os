# 외부 자격 발급 안내

이 파이프라인이 돌려면 자격 두 가지가 필요합니다. 하나는 바로 받을 수 있지만, 다른 하나는 조건을 채워야 받을 수 있습니다.

| 자격 | 소요 | 비용 | 지금 바로 되는가 |
|---|---|---|---|
| YouTube Data API 키 | 5분 남짓 | 무료 | **됩니다** |
| 쿠팡 파트너스 계정 | 1~3 영업일 | 무료 | **됩니다** |
| 쿠팡 파트너스 **API 키** | 누적 판매 15만 원 달성 이후 | 무료 | **안 됩니다. 아래 설명을 꼭 읽어 주세요** |

---

## 먼저 알아 두실 것: 쿠팡 API는 처음부터 쓸 수 없습니다

조사 과정에서 확인한 가장 중요한 제약입니다. 쿠팡 파트너스는 승인이 두 단계로 나뉩니다.

1. **가입 승인**: 개인으로 가입하면 전화번호 인증만으로 거의 바로 됩니다. 이 단계에서도 **링크와 배너를 손으로 만들어 쓸 수 있고 수익도 발생합니다.**
2. **최종 승인**: 누적 판매 금액이 **15만 원**을 넘으면 자동으로 채널 심사가 시작됩니다. 이 심사를 통과해야 **정산을 받을 수 있고, 그때 비로소 API 키 발급 버튼이 활성화됩니다.**

즉 **API로 상품을 자동 검색하는 단계는 처음부터 쓸 수 없습니다.** 초반에는 쿠팡 파트너스 사이트에서 상품 링크를 손으로 만들어 영상 설명란에 넣어야 하고, 누적 판매가 15만 원을 넘긴 다음에야 그 과정을 자동화할 수 있습니다.

이 사실이 계획에 미치는 영향은 문서 맨 아래에 정리해 두었습니다.

> 근거: 쿠팡 파트너스 공식 안내 「[초보자 활동 가이드] 유튜브 활동 시 유의사항」에 이렇게 적혀 있습니다. "판매금액 150,000원을 달성하실 경우, 별도의 신청 절차 없이 자동으로 최종승인 검토 대상이 됩니다."

## 반드시 지켜야 할 표기 규정

쿠팡 파트너스 공식 안내 「[초보자 활동 가이드] 유튜브 활동 시 유의사항」이 요구하는 것입니다. 지키지 않으면 최종 승인에서 반려됩니다.

### 규정 1. 설명란에 대가성 문구를 넣습니다

공정거래위원회 심사지침에 따라, 파트너스 링크가 게재된 **모든 게시물**에 다음 문구가 동반되어야 합니다.

> 이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

**파이프라인이 자동으로 넣습니다.** 빠지면 테스트가 실패합니다.

### 규정 2. 문구가 '더보기'에 가려지면 안 됩니다

가이드가 부적절한 표기로 명시한 경우입니다. "대가성 문구를 확인하기 위해 '자세히 보기'와 같이 추가적으로 클릭이 필요한 경우는 적절한 표기 방식이 아닙니다."

유튜브는 설명의 첫 몇 줄만 보여 주고 나머지를 접습니다. **파이프라인이 고지 문구를 설명 맨 앞에 둡니다.** 상품 링크보다 앞입니다.

### 규정 3. 영상 제목이나 영상 안에도 광고 표시를 합니다

설명란 고지만으로는 부족합니다. 가이드가 반려 사례로 드는 것이 정확히 이 경우입니다. "설명란 또는 댓글에서 대가성 문구와 링크를 적절히 기재했지만 **영상 제목 또는 영상 내에 광고 표시를 하지 않은 경우**."

체크리스트에도 쇼츠가 명시되어 있습니다. "파트너스 링크가 있는 **영상(쇼츠) 제목 또는 영상 내** '유료광고' 등의 경제적 이해관계를 표시했나요?"

가이드가 제시한 방법은 세 가지이고 하나만 하면 됩니다.

| 방법 | 파이프라인 적용 |
|---|---|
| 영상 내에 직접 광고 문구 표시 | — |
| 영상 위에 '유료광고 포함' 배너 표시 | **이것을 씁니다** |
| 영상 제목 앞부분에 `[광고]` 표시 | — |

**파이프라인이 화면 좌측 상단에 '유료광고 포함' 배지를 영상 내내 띄웁니다.** 이 표기는 설정으로 끌 수 없게 만들어 두었습니다.

### 업로드할 때 직접 하셔야 할 것

영상을 올릴 때 유튜브 업로드 화면의 **'유료 프로모션 포함' 체크박스를 켜 주세요.** 파이프라인이 대신 해 줄 수 없는 부분입니다. 규정 3은 배지로 이미 충족되지만, 유튜브 자체 정책도 이 신고를 요구합니다.

## 1. YouTube Data API 키 발급

인기 급상승 목록을 가져오는 데 씁니다. 무료이고 5분이면 끝납니다.

### 절차

1. **구글 클라우드 콘솔에 접속합니다.** <https://console.cloud.google.com> 에 평소 쓰시는 구글 계정으로 로그인합니다. 결제 카드 등록은 필요 없습니다.

2. **새 프로젝트를 만듭니다.** 화면 위쪽 프로젝트 선택 메뉴에서 `새 프로젝트`를 누릅니다. 이름은 `coupang-shorts`처럼 알아보기 쉬운 것으로 정하시면 됩니다.

3. **YouTube Data API v3를 켭니다.** 왼쪽 메뉴에서 `API 및 서비스` → `라이브러리`로 들어가 검색창에 `YouTube Data API v3`를 입력하고, 결과를 눌러 `사용` 버튼을 누릅니다.

4. **API 키를 만듭니다.** `API 및 서비스` → `사용자 인증 정보`로 가서 위쪽의 `사용자 인증 정보 만들기` → `API 키`를 누릅니다. 키 문자열이 바로 나옵니다. `AIza`로 시작하는 39자 문자열입니다.

5. **키에 제한을 겁니다.** 방금 만든 키의 `키 제한`을 눌러 `API 제한사항`에서 `키 제한` → `YouTube Data API v3`만 선택하고 저장합니다. 키가 새어 나가도 다른 API로 요금이 발생하지 않게 막는 조치입니다.

### 할당량

하루 **10,000 유닛**이 무료로 주어집니다. 이 파이프라인이 쓰는 호출은 아래와 같아서 한도에 한참 못 미칩니다.

| 호출 | 유닛 | 하루 사용량 |
|---|---|---|
| 인기 급상승 목록 조회 (`videos.list`) | 1회당 1 | 하루 몇 번 |
| 카테고리 목록 조회 (`videoCategories.list`) | 1회당 1 | 하루 1번 |

주의할 점은 검색(`search.list`)이 1회에 **100 유닛**을 먹는다는 것입니다. 이 파이프라인은 검색을 쓰지 않지만, 나중에 기능을 늘릴 때는 이 비용을 기억해 두시는 편이 좋습니다.

## 2. 쿠팡 파트너스 가입

### 준비물

- 쿠팡 회원 계정 (없으면 먼저 만드셔야 합니다)
- 휴대폰 (본인 인증용)
- 정산받을 은행 계좌
- **활동할 채널 주소** (유튜브 채널). 심사에서 이것을 봅니다

### 절차

1. <https://partners.coupang.com> 에 접속해 쿠팡 아이디로 로그인합니다.
2. 사업자 유형에서 `개인`을 고릅니다. 개인은 별도 서류 없이 전화번호 인증만으로 됩니다.
3. 연락처와 정산 계좌를 입력합니다.
4. **활동 채널로 유튜브 채널 주소를 등록합니다.** 심사에서 이 채널을 보므로, 신청 전에 채널을 만들어 두고 영상을 몇 개 올려 두시는 편이 통과에 유리합니다.
5. 영업일 기준 1~3일 안에 메일로 결과가 옵니다.

### 심사에서 떨어지는 흔한 이유

- 등록한 채널에 콘텐츠가 거의 없는 경우입니다. 빈 채널로 신청하면 거절될 수 있습니다.
- 금지된 콘텐츠가 채널에 있는 경우입니다.

### 가입 직후에 할 수 있는 것

가입 승인만 받아도 쿠팡 파트너스 사이트에서 상품을 검색해 **링크를 손으로 만들어 쓸 수 있습니다.** 영상 설명란에 그 링크를 넣으면 수익이 발생합니다. 여기서 쌓은 누적 판매액이 15만 원을 넘으면 다음 단계로 넘어갑니다.

## 3. 쿠팡 파트너스 API 키 발급 (나중에)

누적 판매 15만 원을 넘겨 **최종 승인**을 받은 다음에 가능합니다.

### 최종 승인을 위해 미리 준비할 것

심사가 시작되면 아래 두 가지를 등록해야 합니다. 평소에 모아 두시면 편합니다.

- **활동 페이지 등록**: 파트너스 링크나 배너를 쓰고 있는 채널 주소를 전부 등록합니다.
- **활동 스크린샷 등록**: 파트너스 활동과 **경제적 이해관계 표시 문구**가 함께 보이는 화면을 캡처해 올립니다. 이 파이프라인은 그 문구를 설명란에 자동으로 넣게 만들 예정이라, 나중에 스크린샷을 뜨기 쉬울 것입니다.

### 발급 경로

쿠팡 파트너스에 로그인한 뒤 상단 메뉴에서 `Tools` → `파트너스 API`로 들어가면, 최종 승인 상태일 때 생성 버튼이 활성화됩니다. 누르면 **액세스 키와 시크릿 키** 두 개가 나옵니다.

### 키를 받은 뒤에 하실 일

**시크릿 키는 다시 볼 수 없으므로 그 자리에서 안전한 곳에 복사해 두셔야 합니다.**

이 저장소는 공개 커밋되므로 키를 파일에 그대로 적으면 안 됩니다. 아래 두 가지 방법 중 하나를 쓰시면 됩니다. 파이프라인이 환경변수를 먼저 보고, 없으면 파일을 읽습니다.

**방법 1. 환경변수** (권장)

```bash
export YOUTUBE_API_KEY="AIza..."
export COUPANG_ACCESS_KEY="..."
export COUPANG_SECRET_KEY="..."
```

**방법 2. 파일** (`.gitignore`에 등록된 경로에만 둡니다)

```bash
cat > ventures/coupang-shorts/.credentials.json <<'EOF'
{
  "youtubeApiKey": "AIza...",
  "coupangAccessKey": "...",
  "coupangSecretKey": "..."
}
EOF
chmod 600 ventures/coupang-shorts/.credentials.json
```

이 방식은 `.claude/mcp-servers/notion-min/server.js:44-52`가 노션 토큰을 다루는 방식과 같습니다. 이미 이 저장소에서 검증된 방법입니다.

## 이 사실이 계획에 미치는 영향

승인받은 계획서는 4단계(수익화)에서 쿠팡 API로 상품을 자동 검색하도록 되어 있습니다. API를 처음부터 쓸 수 없다는 것이 확인되었으므로, 이 단계를 두 시기로 나눠야 합니다.

**1기: 누적 판매 15만 원에 닿기 전 (API 없음)**

파이프라인이 상품을 자동으로 찾는 대신, **어떤 검색어로 상품을 찾으면 좋을지 후보를 뽑아 주는 데까지만** 합니다. 실제 링크는 쿠팡 파트너스 사이트에서 손으로 만들어 넣습니다. `lib/keyword.js`는 이 시기에도 그대로 쓸모가 있고, `lib/publish-meta.js`도 링크 자리만 비워 두면 됩니다.

편당 상품 하나를 손으로 거는 데 2~3분쯤 걸릴 것이고, 하루 5편이면 15분 안팎입니다. 감당할 만한 수준이라고 봅니다.

**2기: 최종 승인 이후 (API 사용)**

계획서에 적은 대로 `lib/coupang.js`와 `lib/budget.js`가 동작합니다. 1기 동안에도 이 두 모듈은 가짜 응답을 주입해 미리 만들어 두고 테스트로 잠가 둘 수 있으므로, 키가 생기면 주입만 바꾸면 됩니다. 계획서에 적은 `--fake` 모드가 정확히 이 용도입니다.

바꿔 말하면 **만들 코드는 달라지지 않고, 언제 실제로 켜지느냐만 달라집니다.** 그래서 계획을 수정하지 않고 그대로 진행해도 됩니다.

## 확인 부탁드릴 것

- 최종 승인 심사에 필요한 **활동 스크린샷**은 파트너스 링크와 대가성 문구가 함께 보이는 화면이어야 합니다. 영상을 올린 뒤 설명란이 펼쳐진 상태로 캡처해 두시면 나중에 편합니다.
