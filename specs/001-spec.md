# 001-spec — 장바구니 기본 기능

## 요구 원문
> "사용자는 상품을 장바구니에 추가하고, 담긴 목록을 확인하고, 수량 변경·삭제할 수 있다"

---

## 가정 (인터뷰 대신)

- **A1. 장바구니 단위**: 단일 인메모리 장바구니 하나만 다룬다. 사용자별/세션별 분리는 범위 밖.
- **A2. 상품 식별**: 상품은 `productId`(문자열), `name`, 단가(`price`)를 가진다. 상품 카탈로그 등록·조회는 범위 밖이며, 담을 때 상품 정보는 주어진 것으로 받는다.
- **A3. 재추가 정책**: 이미 담긴 상품(`productId` 동일)을 다시 추가하면 기존 항목의 수량을 더한다(수량 병합).
- **A4. 수량은 1 이상의 정수**: 0 이하 수량은 유효하지 않은 입력으로 거부한다(예외 반환).
- **A5. 수량 변경 시맨틱**: 수량 변경은 절대값 지정(set). 변경 후 수량 = 지정한 값.
- **A6. 삭제**: 특정 상품 항목 전체를 제거한다. 수량 0 지정(A4에 따라 거부)과 별개 동작.
- **A7. 존재하지 않는 상품 조작**: 담기지 않은 `productId`에 수량 변경/삭제 시도 시 거부.
- **A8. 목록 조회 결과**: 담긴 항목(상품 정보 + 수량)과 합계 금액(단가×수량 총합)을 반환. 빈 장바구니는 빈 목록과 합계 0.
- **A9. 영속화 없음**: 프로세스 메모리에만 존재, 재시작 시 초기화.

---

## 시나리오

### S01. 빈 장바구니에 상품 추가
- Given: 비어 있는 장바구니
- When: `productId=P1`, 수량 2인 상품을 추가한다
- Then: 장바구니에 P1 항목이 수량 2로 존재한다

### S02. 서로 다른 상품 여러 개 추가
- Given: 비어 있는 장바구니
- When: P1(수량 1), P2(수량 3)을 순서대로 추가한다
- Then: 장바구니에 P1(수량 1), P2(수량 3) 두 항목이 존재한다

### S03. 이미 담긴 상품 재추가 시 수량 병합 (A3)
- Given: P1이 수량 2로 담긴 장바구니
- When: 동일한 P1을 수량 3으로 추가한다
- Then: 항목은 여전히 하나이며 P1의 수량은 5가 된다

### S04. 0 이하 수량으로 추가 시 거부 (A4)
- Given: 비어 있는 장바구니
- When: P1을 수량 0(또는 음수)으로 추가한다
- Then: 추가가 거부되고 오류가 발생하며, 장바구니는 비어 있는 상태로 유지된다

### S05. 담긴 목록 조회 (A8)
- Given: P1(수량 2, 단가 1000), P2(수량 1, 단가 500)이 담긴 장바구니
- When: 목록을 조회한다
- Then: P1(수량 2), P2(수량 1) 두 항목과 합계 금액 2500이 반환된다

### S06. 빈 장바구니 조회 (A8)
- Given: 비어 있는 장바구니
- When: 목록을 조회한다
- Then: 빈 목록과 합계 0이 반환된다

### S07. 수량 변경 (절대값 지정) (A5)
- Given: P1이 수량 2로 담긴 장바구니
- When: P1의 수량을 5로 변경한다
- Then: P1의 수량은 5가 된다

### S08. 0 이하 값으로 수량 변경 시 거부 (A4)
- Given: P1이 수량 2로 담긴 장바구니
- When: P1의 수량을 0(또는 음수)으로 변경한다
- Then: 변경이 거부되고 오류가 발생하며, P1의 수량은 2로 유지된다

### S09. 담기지 않은 상품의 수량 변경 시 거부 (A7)
- Given: P1만 담긴 장바구니
- When: 담긴 적 없는 P9의 수량을 3으로 변경한다
- Then: 조작이 거부되고 오류가 발생하며, 장바구니 상태는 변하지 않는다

### S10. 상품 삭제 (A6)
- Given: P1(수량 2), P2(수량 1)이 담긴 장바구니
- When: P1을 삭제한다
- Then: 장바구니에는 P2(수량 1)만 남는다

### S11. 담기지 않은 상품 삭제 시 거부 (A7)
- Given: P1만 담긴 장바구니
- When: 담긴 적 없는 P9를 삭제한다
- Then: 조작이 거부되고 오류가 발생하며, 장바구니 상태는 변하지 않는다

### S12. 마지막 상품 삭제로 빈 장바구니 복귀
- Given: P1만 담긴 장바구니
- When: P1을 삭제한다
- Then: 장바구니는 비어 있고, 조회 시 빈 목록과 합계 0이 반환된다
