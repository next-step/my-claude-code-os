# QA 발견 패턴 메모리

qa-engineer가 버그 리포트를 작성할 때마다 이 파일에 패턴을 누적한다.
backend-dev는 **구현 시작 전** 이 파일을 읽고 같은 패턴이 반복되지 않도록 사전 차단한다.

---

## 작성 규칙

새 패턴 발견 시 아래 형식으로 추가한다:

```
### [P-번호] 패턴 이름
- **레이어**: 서비스 / 컨트롤러 / 리포지토리 / 뷰
- **종류**: NPE / 인증 누락 / 경계값 / 트랜잭션 / N+1 / XSS / 기타
- **발견 일자**: YYYY-MM-DD
- **발생 조건**: (어떤 상황에서 터지는지)
- **사전 차단법**: (backend-dev가 구현 시 미리 적용할 것)
```
