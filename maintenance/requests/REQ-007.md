## 1. 요청 원문

정산시스템에 월별 정산 내역을 엑셀로 내보내는 기능을 추가해주세요.

### 추가 확인 (intake-interview → 담당자 응답)

- 목적: 사내 회계·재무팀 보고서 작성용
- 범위: 특정 파트너/거래처 단위로 선택해서 내보내기 (전사 통합 아님)
- 완료 기준: 회사A의 기존 정산서 표준 양식(컬럼·서식)에 맞아야 함

## 2. 접수 정리 (/intake)

- 유형: 기능개선
- 영향 범위: `정산시스템` (외주 `회사A` 전담 — 사내 팀 접근 권한 없음). 이 요청은 사내 개발
  착수가 아니라 **회사A 앞으로 보낼 요구사항 정리**
- 완료 기준(초안):
  1. 파트너/거래처 단위로 선택해 월별 정산 내역을 엑셀로 내보낼 수 있음
  2. 회사A의 기존 정산서 표준 양식(컬럼·서식)과 일치
  3. 사내 회계·재무팀이 실제로 보고서 작성에 바로 쓸 수 있음

## 3. 분류 결과 (classifier)

## 분류 결과
- 판단: **outsource**
- 규모: **M**
- 신뢰도: 높음
- 근거:
  1. `정산시스템`은 사내 팀에 코드·배포 접근 권한이 없고, 계약상 `회사A`가 설계·운영을
     전담한다 (`.claude/knowledge/systems/정산시스템.md`).
  2. `classification-policy.md` §0 선판정의 "접근 권한 자체가 없음" 및 "계약상 특정 벤더
     전담" 두 조건이 동시에 해당 — 다른 조건(캐파·팀 스택)을 볼 필요 없이 바로 확정.
  3. 규모는 신규 엔드포인트·양식 일치 검증이 필요해 `sizing.md` 기준 M — 단 §0 선판정이
     이미 결론을 확정했으므로 규모는 참고용.
  4. `maintenance/capacity.md`의 `회사A` 잔여율 45%는 §2 캐파 룰(20% 미만) 발동 조건에
     해당하지 않음 — 애초에 §0에서 결론이 끝났으므로 영향 없음.
- 적용한 기준:
  - `classification-policy.md` §0 — "접근 권한 없음" + "계약상 특정 벤더 전담" 해당, 선판정 outsource
  - `.claude/knowledge/systems/정산시스템.md` "관리·계약" — 관리주체 회사A 전담
  - `maintenance/capacity.md` 2026-09-15(유효) — 회사A 잔여 45%, §2 미발동(참고용)
  - `.claude/context/sizing.md` 루브릭 — 신규 엔드포인트 + 양식 검증 → M
- 확인이 필요한 점: 없음 — §0 선판정 두 조건이 명확히 충족

## 7. 외주 요청서 (/outsource) — 외주인 경우

- 배경 / 문제: 사내 회계·재무팀이 `정산시스템`의 월별 정산 내역을 보고서 작성에 쓰는데,
  현재 엑셀로 내보내는 기능이 없어 수작업으로 옮겨 적고 있습니다.

- 요청 범위:
  1. `정산시스템`에 월별 정산 내역 엑셀(.xlsx) 내보내기 기능 추가
  2. 파트너/거래처 단위로 선택해서 내보낼 수 있어야 함
  3. 기존 정산서 표준 양식(컬럼·서식)과 동일하게

- 범위 밖:
  - 전사 통합 정산 내역 일괄 내보내기 (이번엔 파트너/거래처 단위 선택만)
  - 정산 로직 자체의 변경 — 기존 계산 결과를 내보내기만 함

- 산출물:
  - 엑셀 내보내기 기능이 반영된 `정산시스템` 업데이트
  - 사용 방법 간단 안내(화면 위치, 선택 방법)

- 완료·인수 기준:
  1. 특정 파트너/거래처를 선택해 월별 정산 내역을 `.xlsx`로 내보낼 수 있음을 시연
  2. 내보낸 파일이 회사A의 기존 정산서 표준 양식(컬럼·서식)과 일치
  3. 사내 회계·재무팀 담당자가 실제로 받아 보고서 작성에 문제없이 사용

- 제약 조건:
  - 파일 형식 `.xlsx`
  - 기존 정산서 표준 양식(컬럼·서식) 준수 — 회사A 보유 양식 기준

- 필요한 접근 권한 / 우리가 제공할 것:
  - `정산시스템`은 회사A 전담이라 우리 쪽에서 제공할 접근 권한 없음 — 회사A가 자체 보유한
    시스템·양식 기준으로 진행

- 일정: `(확인 필요)` — 희망 착수·납기 미정

- 커뮤니케이션: `(확인 필요)` — 담당 창구 미정 (요청자 미상)

- 예산 / 비고: 예산 `협의`. `maintenance/capacity.md`의 `회사A` 계약(4.0 M/M, 잔여 45%) 범위
  안에서 처리 가능한지 회사A와 확인 필요.
