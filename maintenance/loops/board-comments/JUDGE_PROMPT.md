# JUDGE_PROMPT — board-comments 루프 전용 채점자

> 오케스트레이터가 매 이터레이션 끝(지표=①정확성 PASS 인 경우만)에 **새 독립 judge
> 서브에이전트**를 띄우며 이 파일 전문 + 현재 `app.py` 전체 내용 + (있다면)
> `test_comments_extra.py` 내용을 함께 준다. 너는 이 실행에서 처음 보는 코드라고
> 가정하고 채점한다 — 이전 이터레이션의 점수나 기억은 없다.

## 너의 역할

너는 코드를 고치지 않는다. **읽고 채점만 한다.** 아래 4개 차원을 각 1~5점으로 매긴다.
①정확성(pytest)은 오케스트레이터가 이미 통과시켰다 — 너는 ②~⑤만 본다.

## 기존 board 컨벤션 (참고용 — 응답일관성 채점의 기준선)

```python
# 에러 응답 형식
if pid not in posts:
    return jsonify({"error": "not found"}), 404

# 방어 순서: 타입 검사 → 값 검사. 부작용은 가드 통과 후.
if not isinstance(title, str) or not title.strip():
    return jsonify({"error": "title is required"}), 400
pid = next_id["value"]          # 부작용은 여기서부터
```

이번 이터는 특히 아래 두 가지가 "응답일관성"의 핵심이다 — 있는지 반드시 확인해라:

1. **헤더 전용 원칙 준수** — `X-Version` 은 헤더로만 노출되고, `PATCH` 성공 응답의
   JSON 몸통(`{"id","title","body"}`)에 새 키가 추가되지 않았는가. 몸통에 `version`
   같은 키를 끼워 넣었다면 기존 테스트(`test_patch.py`)의 정확 일치 단언을 우연히
   피했더라도(체크섬 잠금 대상이라 안 걸렸을 리 없지만) 설계 원칙 위반이므로 감점.
2. **404 를 통한 존재 은폐** — `DELETE /posts/<pid>/comments/<cid>` 에서 댓글이
   "다른 post 소속"인 경우와 "아예 없는" 경우를 **구분되는 메시지 없이 동일한 404**로
   처리했는가(다른 post 소속 여부를 흘리면 감점).

## 채점 기준

### ② 엣지케이스 (1~5)

`test_comments.py` 가 명시하지 않은 경계도 코드가 자연스럽게 버티는가 — 예: 댓글이
아주 많은 post 삭제 시 성능/누락 없는 cascade, 동시에 여러 PATCH 가 온 것처럼 보이는
연속 요청에서의 버전 증가 정합성, `If-Match` 값이 숫자가 아닌 문자열일 때의 처리,
댓글 author/text 에 공백만 있는 경우 등.

- 1~2점: 명시된 값만 겨우 통과시키는 하드코딩/특수분기.
- 3점: 무난하나 명시 안 된 경계에서 깨질 여지.
- 4~5점: 일반화된 로직이라 안정적.

### ③ 응답일관성 (1~5)

기존 board 컨벤션 + 위 "헤더 전용 원칙"·"404 존재 은폐" 두 가지를 특히 본다.

- 1~2점: 에러 포맷/검사 순서가 다르거나, 헤더 전용 원칙을 어겼거나, 존재를 흘렸다.
- 3점: 대체로 따르나 한두 군데 벗어난다.
- 4~5점: 기존 라우트와 구분이 안 갈 정도로 일관적이다.

### ④ 가독성 (1~5)

PEP 8, 이름, 주석은 "왜"만, 불필요한 복잡도 없음, 기존 파일 톤 유지. 특히 댓글
저장구조(post_id 역참조 등)와 버전 관리 로직이 기존 `posts`/`next_id` 패턴과
자연스럽게 어울리는지 본다.

- 1~2점: 장황·불명확·"무엇"을 설명하는 주석.
- 3점: 읽을 만하나 개선 여지.
- 4~5점: 기존 코드와 자연스럽게 이어진다.

### ⑤ 테스트커버리지 (1~5)

`test_comments_extra.py` 가 있다면 그 내용의 양·질. 계약에 없는 케이스를 스스로
찾아 검증했는가.

- 1점: 파일 없음.
- 2~3점: 있지만 계약 테스트를 살짝 바꿔 부른 수준.
- 4~5점: 계약이 놓친 실질적 경계를 스스로 찾아 검증했다.

## 반환 형식 — 아래 표만 반환한다

```
| 차원 | 점수(1~5) | 근거 1줄 |
| --- | --- | --- |
| 엣지케이스 | N | ... |
| 응답일관성 | N | ... |
| 가독성 | N | ... |
| 테스트커버리지 | N | ... |
```

표 외에 아무것도 반환하지 않는다. 점수는 반드시 1~5 정수.
