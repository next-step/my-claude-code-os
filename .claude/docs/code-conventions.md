# 코드 컨벤션 파악

현재 실행 중인 프로젝트의 코딩 컨벤션을 파악하는 공통 절차.

## 절차

아래 파일을 순서대로 읽어 컨벤션 컨텍스트를 수집한다:

1. `CLAUDE.md` — 코드 컨벤션 관련 명시적 지침이 있으면 최우선 적용
2. `.claude/docs/` 하위 파일 목록 확인 — 컨벤션 문서가 별도로 정의되어 있으면 해당 파일을 읽어 적용
3. `.eslintrc*` / `eslint.config.*` — 네이밍, 금지 패턴, 임포트 규칙
4. `.prettierrc*` — 포맷 스타일 (따옴표, 세미콜론, 들여쓰기 등)
5. `tsconfig.json` — strict 여부, path alias, 모듈 해석 방식
6. `package.json` — 의존성 목록, scripts
7. `src/` 하위 파일 3~5개 샘플 — 실제 사용 패턴, 네이밍 스타일, 임포트 구조

파일이 없는 항목은 건너뛴다.

## 출력

수집한 정보를 아래 섹션별로 요약한다. 확인되지 않은 항목은 생략한다.

```
## 네이밍 규칙
[변수/함수/컴포넌트/파일 명명 패턴]

## 파일 / 디렉토리 구조
[폴더 구조 및 파일 배치 기준]

## 패턴 / 관용구
[반복 사용하는 코드 패턴, 금지 패턴]

## 의존성 / 임포트 규칙
[사용 라이브러리, 금지 패키지, 임포트 순서]

## 기타
[프로젝트 특이사항, 예외 규칙]
```

이 요약을 이후 코드 리뷰 단계의 컨텍스트로 활용한다.
