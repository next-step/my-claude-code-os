# 보안 체크

커밋 직전 민감 파일이 포함되지 않았는지 확인하는 공통 규칙. 커밋을 수행하는 모든 스킬은 이 규칙을 따른다.

---

## 체크 명령

```bash
git diff --cached --name-only | grep -E '\.env|secrets|credentials'
```

| 패턴          | 대상                                  |
| ------------- | ------------------------------------- |
| `\.env`       | 환경 변수 파일 (.env, .env.local 등)  |
| `secrets`     | 시크릿 관련 파일/디렉토리             |
| `credentials` | 인증 정보 파일                        |

---

## 감지 시 동작

- 커밋을 진행하기 전 **반드시 경고**하고 사용자에게 확인받는다.
- 사용자의 명시적 허가 없이는 커밋을 중단한다.
- `--no-verify` 등 훅 우회 플래그는 사용자가 명시적으로 요청할 때만 사용한다.
