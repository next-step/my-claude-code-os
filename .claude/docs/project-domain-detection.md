# 프로젝트 도메인 파악

현재 실행 중인 프로젝트의 도메인을 파악하는 공통 절차.

## 절차

아래 파일을 순서대로 읽어 도메인 컨텍스트를 수집한다:

1. `CLAUDE.md` — 프로젝트 설명, 도메인 특이사항
2. `package.json` (또는 `build.gradle`, `build.sh`, `pyproject.toml` 등) — 프로젝트 이름, 주요 의존성
3. `README.md` — 서비스 개요 (없으면 생략)

파일이 없는 항목은 건너뛴다.

## 출력

수집한 정보를 아래 형식으로 한 줄 요약한다:

```
[서비스명] — [스택], [서비스 설명]
```

예시:
- `파트너 어드민 웹 — React/TypeScript, 캐시딜 내부 파트너 관리도구`
- `정산 API 서버 — Spring Boot/Kotlin, 캐시딜 정산 처리 백엔드`
- `CMS — Next.js/TypeScript, 운영팀 콘텐츠 관리도구`

이 요약을 이후 단계의 컨텍스트로 활용한다.
