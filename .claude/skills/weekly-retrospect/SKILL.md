# weekly-retrospect — 주간 회고 (하루 루프 F단계)

> 설계 근거: docs/interviews/2026-07-08-daily-trading-loop.md (Q28·Q29·Q30 + F 세션) + 2026-07-08-os-docs-overhaul.md (Q7 파급)

한 주가 끝나면, **계획을 세운 바로 그 위원회 전문가 에이전트(회고 모드로 축약 재소집)**가 자기 판단을 되짚어 개선안을
도출한다. 계획한 주체가 반성해야 '판단→결과'의 연속성이 산다(OS.md F). 이 스킬은 개선안을
**제안까지만** 무인으로 만든다 — 스크립트 상수·docs/OS.md에 실제 반영하는 튜닝은 **사람 승인
후**에만 하고, 표본 부족 가설은 반영하지 않고 대기열에 기록한다(무결성 가드레일).

작업 전 규약·정의를 Read로 먼저 읽는다:
- `.claude/context/committee-personas.md` — 위원회 7인 명단·공통 규약 인덱스. 회고는 이 명단에서 렌즈를 골라 같은 `committee-*` 에이전트를 **회고 모드로 스폰**해 재사용한다(렌즈 정의는 각 에이전트 md가 진실원천).
- `.claude/context/record-conventions.md` — 상태 vs 사건(append) 분리, 기록물 5종과 책임. 회고 리포트는 사건(append) 로그다.
- `.claude/context/loop-lessons.md` — 표본 부족(n=0~1) 가설의 '표본 대기' 기록 대기열. 회고가 여기에 append한다.
- `.claude/context/data-sources.md` — 출처 표기 규칙(스크립트 값엔 스크립트명, 못 구한 값은 "확인 불가").
- `.claude/context/investor-profile.md` · `.claude/context/trading-principles.md` — 방향타(위험 허용도 중립)와 무결성·튜닝 승인 가드레일.

## 무엇을 되짚나 (F2)

입력은 **결과 + 판단 이력** 둘 다다. 하나만 보면 '실력 vs 시장 휩쓸림'을 못 가른다.
- **결과**: 체결(`data/fills/`)·현재 손익(`data/portfolio.md`).
- **판단 이력**: 위원회 회의록(`data/minutes/`, 국면 판단·계획 변경 근거)·국면 판정 앵커
  (회의록의 국면 합의 정량치, `scripts/market_regime.py` 계열)·계획 변경(`data/investment-plan.md`).

핵심 질문: **"왜 그 판단을 했고, 결과가 어땠나."** 좋은 결과가 실력인지 시장에 휩쓸린 운인지,
나쁜 결과가 판단 오류인지 불가항력인지를 렌즈별로 가른다.

## 실행 절차

### 1단계 — 결정론 status 집계 (사실판)

축약 위원회가 딛을 **결정론적 사실판**을 스크립트로 만든다. 기억·추정이 아니라 기록물 집계다.

```bash
# 오늘(토요일) 기준 최근 7일 루프 기록물을 한 번에 집계 → JSON 사실판
# --append-health-ledger: 무결성 건강도를 창 종료일 키로 주별 원장에 멱등 append(추세 시계열 축적).
python3 "$CLAUDE_PROJECT_DIR/scripts/weekly_retro_status.py" --end <YYYY-MM-DD> --days 7 --append-health-ledger
```

- 출력 JSON은 창(window) 안의 **회의록(국면 합의·계획 결정·긴급 여부)·체결 인벤토리·계획 상태
  라벨 집계·포트폴리오 손익 추출**을 담는다. 이 값을 **정량 사실**로 토론에 싣는다.
- `integrity_health` 블록은 그 주 계획서(`investment-plan.md`) **내부 자기정합 점검 4종**(①근거 유무
  ②손절가≥진입가 ③목표가≤진입가 ④수량이 양의 정수 아님)의 `점검/위반/건강도(=1−위반/점검)`와
  `위반내역[]`·`확인불가[]`를 담는다. 값이 없어 판정 못 한 셀은 위반이 아니라 **확인 불가**다(무결성 1 —
  날조 금지). `--append-health-ledger`를 붙이면 이 요약 한 줄이 `data/health/integrity-health.jsonl`에
  창 종료일(window_end) 키로 **멱등 append**된다(같은 주 재실행은 중복 추가 안 함). 리포트의 추세 절은
  이 원장을 읽어 렌더한다.
- 스크립트가 `확인 불가`/`null`로 낸 항목(특히 **주간 수익률**은 포트폴리오가 상태 파일이라
  결정론 산출 불가)은 그대로 두고 추정치로 채우지 않는다(무결성 1·3). 위원회는 체결 로그·회의록의
  체결가로 정성 판단하되 없는 수치를 지어내지 않는다.
- 회의록·체결이 창 안에 하나도 없으면(exit 1) 되짚을 사건이 없다는 뜻 — 사용자에게 알리고,
  초기 주라면 "이번 주 표본 없음"으로 리포트를 짧게 남긴다(억지 개선안 생성 금지).
- 원본이 필요하면 status가 가리키는 파일 경로(`entries[].path`·`files`)를 직접 Read해 렌즈별
  주장의 근거를 확인한다.

### 2단계 — 축약 위원회 수렴 토론 (F1)

메인 스킬이 **사회자**로, 정규 위원회와 **같은 `committee-*` 에이전트**를 회고 초점 렌즈만 골라
**회고 모드로 스폰**해 렌즈별로 자기 판단을 되짚게 한다(in-context 연기 아님 — 렌즈 정의는 각
에이전트 md가 진실원천, 정의 중복 금지). 정규 위원회(순차 토론·수렴 판정)의 오케스트레이션을
차용하되, 여기서는 **과거 판단의 사후 검증**이 주제다. 각 에이전트에 넘기는 것: 1단계 status
사실판 + 회고 창의 회의록·체결·손익 요약 + **모드=회고 축약**.

- **축약 구성(회고 초점)**: 계획을 실제로 가른 렌즈를 중심에 둔다(해당 에이전트만 스폰).
  - **기술(`committee-technical`)·거시(`committee-macro`)**: 국면 판정이 맞았나(회의록 국면 합의 vs 이후 전개).
  - **수급(`committee-flow`)·펀더멘털(`committee-fundamental`)**: 진입·비중·목표가 근거가 결과로 검증됐나.
  - **리스크(`committee-risk`)**: 손절·총 리스크 규율이 지켜졌나, 하방이 계산대로였나.
  - **회의론자(`committee-skeptic`) — 필수**: **자화자찬 견제.** 좋은 결과를 실력으로 착각하지 않도록,
    "그 수익이 판단 덕인가 시장이 다 올라서인가", "손실을 피한 게 규율인가 운인가"를 반대신문한다.
    심리(`committee-sentiment`)는 군중 심리에 휩쓸린 판단이 있었는지를 보탠다(축약 시 회의론자에 흡수 가능 — 스폰 생략).
- **되짚기 축(렌즈 공통 질문)**: ① 국면 판정이 사후에도 맞았나 ② 계획(진입·손절·비중)이 근거대로
  결과를 냈나 ③ 결과가 실력인가 시장 휩쓸림인가 ④ 반복되는 패턴(임계·배점·손절폭·비중·페르소나
  가중)이 보이나.
- **수렴 판정(정규 위원회 차용)**: 사회자가 렌즈별 되짚기를 모아 **합의된 교훈 한 줄들**과 남은
  이견을 정리한다. 개선안은 ④에서 나온 **패턴 가설**로 좁힌다 — 한 주 관찰만으로 단정하지 않는다.
- **사실·수치는 출처에서만.** 에이전트는 해석 렌즈만 얹고, 정량치는 1단계 status·원본 기록에서만
  가져온다(committee-personas 공통 규약, 무결성 가드레일).

### 3단계 — 회고 리포트 append 저장

- 경로: `data/retrospectives/YYYY-MM-DD.md` (record-conventions 사건 로그, **append-only 박제**).
  `YYYY-MM-DD`는 회고를 연 토요일. 같은 주 재실행은 덮지 말고 `-2`, `-3` 접미사로 새 파일.
- 저장 디렉터리가 없으면 만든다: `mkdir -p "$CLAUDE_PROJECT_DIR/data/retrospectives"`.
- **한 번 쓰면 고치지 않는다.** 개선안 채택·기각 여부가 나중에 갈려도 이 리포트는 그대로 두고,
  결론은 loop-lessons(대기열)나 승인 반영 이력이 맡는다.

#### 회고 리포트 스키마

```markdown
# 주간 회고 YYYY-MM-DD (창: YYYY-MM-DD ~ YYYY-MM-DD)

## 이번 주 사실 (weekly_retro_status.py)
- 회의록 N건(긴급 M건) · 체결 K건 · 계획 상태: 대기 a / 진행중 b / 완료 c
- 손익(포트폴리오): 현금·평가손익·총평가액 (출처: portfolio.md)  · 주간 수익률: 확인 불가(상태 파일 한계)

## 무결성 건강도 (weekly_retro_status.py integrity_health)
- 이번 주: 점검 <점검>건 · 위반 <위반>건 · 건강도 <건강도>(=1−위반/점검, 점검 0이면 확인 불가)
- 위반내역: <종목·점검·값 나열, 없으면 "없음">  · 확인 불가(미기재): <종목·점검, 없으면 "없음">
- 최근 N주 추세(data/health/integrity-health.jsonl): <window_end: health 시계열 — 예 07-04:1.0 → 07-11:0.89>
  - 추세가 신호다. 초기엔 1.0이 정상이고 **위반이 처음 잡힌 주**가 되짚을 대상. 한 주 하락만으로 단정하지 않는다.

## 렌즈별 되짚기
- 기술/거시(국면): <국면 판정이 사후에도 맞았나 — 근거 수치>
- 수급/펀더멘털(계획): <진입·비중·목표 근거가 결과로 검증됐나>
- 리스크(규율): <손절·총 리스크가 지켜졌나>
- 회의론자(탈레브): <자화자찬 견제 — 실력 vs 시장 휩쓸림 판정 한 줄>

## 합의된 교훈
- <실력이었던 것 / 운이었던 것 / 판단 오류였던 것>

## 개선안 (패턴 가설)
- <임계·배점·손절폭·비중·페르소나 가중 등> — 근거 표본 수 n=<>, 승인 대상/표본 대기 구분
```

### 4단계 — 되먹임: 승인 게이트 & 표본 대기 (F3)

개선안 도출은 무인이지만 **반영은 사람 승인 후**다(trading-principles 무결성 4·5). 개선안을
표본 크기로 갈라 처리한다.

- **표본 충분(반복 관찰된 패턴)**: 사용자에게 **제안**으로 올린다. 승인되면 그때 해당
  스크립트 상수(예: morning-briefing `N`, 국면 임계 등)와 `docs/OS.md`를 **함께** 고쳐 다음 루프가
  자동 적용하게 한다. 승인 전에는 어떤 상수·문서도 바꾸지 않는다. **이 스킬은 승인 없이는 반영하지
  않는다** — 상수·문서 편집은 사용자 승인 이후 별도로 수행한다.
- **표본 부족(n=0~1)**: 즉시 반영 금지. `.claude/context/loop-lessons.md`의 "## 교훈 대기열"에
  **append**한다 — 한 줄 가설 + 관찰 근거(날짜·표본 수) + 상태(표본 대기). 같은 패턴이 반복돼
  표본이 쌓이면 그때 승인 경로로 올린다. 반영·기각되면 결론(사유·날짜)을 붙여 이력으로 남긴다.

#### loop-lessons 기록 형식(대기열에 append할 한 줄)

```markdown
- (YYYY-MM-DD, n=<표본 수>) <개선 가설 한 줄> — 근거: <status/회의록 관찰>. 상태: 표본 대기.
```

- **주간 리포트를 위원회 일일 입력에 상시 주입하지 않는다.** 반영된 개선은 상수·문서에 녹아
  자동 적용되고, 미반영 가설은 대기열에 머문다(loop-lessons 용도와 정합).

## 튜닝 상수

- `--days 7` — 회고 창 길이(주간). status 스크립트 인자로 전달한다. 회고가 조정을 제안할 수 있는
  값이며, 변경은 사람 승인 후 반영한다(무결성 4).

## 이 스킬이 하지 않는 것
- 승인 없는 튜닝 반영. 스크립트 상수·docs/OS.md 변경은 사람 승인 후에만(무결성 4·5).
- 소표본(n=0~1) 즉시 반영. 가설은 loop-lessons 대기열로 보낸다.
- 사실·수치 생성. 정량치는 status 스크립트·원본 기록 출처만 쓴다. 주간 수익률처럼 결정론 산출
  불가한 값은 "확인 불가"로 둔다(무결성 1·3).
- 회고 리포트 수정·삭제(append-only 박제). 결론이 갈려도 리포트는 그대로 둔다.
- 매매·체결·계획 갱신(→ 위원회 B·시뮬 엔진). 회고는 되짚기·개선 제안까지다.
```
