# Compare — 실험 전후 비교 리포트

## Overview

실험 기록 2개 이상을 비교한 마크다운 리포트를 만든다. 기록 읽기와 리포트
작성은 `compare-reporter`에 위임한다 — 기록이 쌓일수록 메인 컨텍스트에 다
올리는 비용이 커지므로, 독립 컨텍스트에서 읽고 리포트만 회수한다.

## 절차

| # | 담당 | 단계 |
|---|------|------|
| 1 | 🟢 메인 | **대상 확인** — 인자로 받은 실험 번호 사용. 없으면 최근 2개를 기본 제안하고 확인받는다 |
| 2 | 🟣 reporter | **비교 리포트** — 스폰 입력: 실험 번호들, `experiments/` 경로, `metrics.md` 경로. 리포트 텍스트만 회수 |
| 3 | 🟢 메인 | **제시** — 리포트를 사용자에게 전달. 파일로 저장하지 않는다 (저장을 원하면 사용자가 지시 — 저장 위치는 개인 성격이면 `private/notes/`) |

## 불변 규칙

1. **창작 금지**: 리포트의 모든 내용은 실험 기록·metrics.md에 근거해야 한다.
   기록에 없는 수치·해석을 만들어내지 않는다.
2. **판정 재해석 금지**: 각 실험의 판정(채택/미달/인계)은 기록된 그대로 옮긴다.
   비교 관점의 관찰은 "관찰" 절에 분리한다.
3. **기록 격리 유지**: 리포트에도 대상 프로젝트의 파일명·코드 정보를 쓰지 않는다
   (기록 자체가 격리돼 있으므로 인용만 하면 자연히 지켜진다).
4. 시각화(차트·다이어그램)는 만들지 않는다 — 향후 확장 지점 (필요해지면 별도 설계).

## Common Mistakes

| 실수 | 해결 |
|---|---|
| 메인이 experiments/ 전체를 직접 읽음 | 읽기는 reporter 담당 — 리포트만 회수 |
| 리포트를 임의로 파일 저장 | 대화 제시가 기본, 저장은 사용자 지시가 있을 때만 |
| 두 실험의 측정 셋이 다른데 수치를 직접 비교 | 측정 셋·판정 기준 차이를 리포트에 명시하도록 스폰 입력에 포함 |
