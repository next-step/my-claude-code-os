# morning-briefing — 아침 뉴스 수집 (하루 루프 A단계)

> 설계 근거: docs/interviews/2026-07-08-daily-trading-loop.md (Q4·Q5·Q6·Q7)

개장 전 **판단을 바꾸는 사실**만 수집해 '오늘의 브리핑'으로 구조화 저장한다. 이 스킬은 사실을
모으기만 하고, 그 사실로 무엇을 살지/팔지는 **투자 위원회(B단계)**가 판단한다 — 위원회 토론 전에
편향을 주입하지 않기 위해 브리핑에 매수/매도 해석을 넣지 않는다.

작업 전 규약 2종을 Read로 먼저 읽는다:
- `.claude/context/data-sources.md` — 정성↔정량 분담·채택 소스·출처 표기 규칙.
- `.claude/context/record-conventions.md` — 사건 로그(append-only) 저장 규약.

## 수집 범위 (Q4)

| 축 | 항목 | 수집 방식 |
|----|------|-----------|
| 정성 | 국내 경제·시장 헤드라인, 미국장 마감(지수·반도체 SOX), 거시 내러티브(금리·환율·업종 로테이션) | `kr-macro-researcher` 서브에이전트(웹검색) |
| 정성 | 보유/관심 종목 개별 뉴스 | `company-news-researcher` 서브에이전트(종목별 병렬) |
| 정량 | 전일 지수(코스피·코스닥), 원/달러 환율, 수급(외국인·기관 전일 순매수) | `scripts/morning_quant.py`(네이버 파싱) |

- 공시/DART는 **제외**한다(data-sources 유지). 정밀 수치는 웹검색이 아니라 스크립트가 진실원천 —
  서브에이전트는 그 위에 내러티브 색깔만 보탠다.

## 실행 절차

### 1단계 — 대상 종목 파악
- `data/portfolio.md`(보유)와 `data/investment-plan.md`(관심/대기)가 있으면 종목 목록을 뽑아
  `company-news-researcher` 호출 대상으로 삼는다. 두 파일이 아직 없으면(초기 상태) 종목 뉴스 축은
  "대상 종목 없음"으로 두고 거시·정량 축만 수집한다(억지 종목 생성 금지).

### 2단계 — 정성·정량 병렬 수집
한 번에 다음을 **병렬**로 띄운다(서로 의존 없음):
- **거시·미국장**: `kr-macro-researcher`를 "현재 환경 모드"로 호출하되, 국내 거시에 더해
  **미국장 마감(다우·나스닥·S&P·필라델피아 반도체 지수)과 반도체 업황**을 정책·글로벌 변수로
  함께 조사하도록 지시한다.
- **종목 뉴스**: 대상 종목마다 `company-news-researcher`를 하나씩 병렬 호출한다.
- **정량 스냅샷**: 스크립트를 실행한다.
  ```bash
  python3 "$CLAUDE_PROJECT_DIR/scripts/morning_quant.py"
  ```
  출력의 지수·환율·수급 마크다운 블록을 그대로 정량 축에 싣는다. `--json`은 값이 필요할 때 쓴다.
  스크립트가 "확인 불가"로 표기한 항목은 그대로 "확인 불가"로 브리핑에 옮긴다 —
  **빈 자리를 웹검색 추정치로 채우지 않는다**(무결성 가드레일).

### 3단계 — 구조화 (사실 추출·중복제거)
수집 결과를 아래 **브리핑 스키마**로 정리한다. 같은 사건의 중복 기사는 하나로 묶고, **원본 전문은
저장하지 않고 링크만** 둔다(Q5). 정량 수치에는 산출 주체(`morning_quant.py`)를, 정성 항목에는
출처 URL을 붙인다. 매수/매도·비중 같은 **투자 해석은 넣지 않는다**.

### 4단계 — append-only 저장
- 경로: `data/briefings/YYYY-MM-DD.md` (record-conventions 사건 로그 규약).
- **한 번 쓰면 고치지 않는다.** 같은 날 재실행은 덮지 말고 `YYYY-MM-DD-2.md`, `-3.md`로 새 파일.
- 저장 디렉터리가 없으면 만든다: `mkdir -p "$CLAUDE_PROJECT_DIR/data/briefings"`.

### 5단계 — 소비 윈도우 노출 (Q7)
- 위원회 주입용으로 **오늘 브리핑 전문 + 최근 N영업일 브리핑**을 노출한다.
- **N은 튜닝 상수, 기본 N=5.** 값은 이 SKILL.md 아래 "튜닝 상수"에 둔다(진실원천 한 곳).
  최근 N개는 `data/briefings/`의 날짜 파일을 최신순 정렬해 N건을 고른다(같은 날 `-2` 등은 그날 1건으로 셈).

## 브리핑 스키마

```markdown
# 아침 브리핑 YYYY-MM-DD

## 정량 스냅샷 (전일)
<scripts/morning_quant.py 출력 블록 — 지수·환율·수급, 각 값에 출처(스크립트명)>

## 거시·미국장 (정성)
- [국내] (날짜) 헤드라인 — 한 줄 사실 요약  · 출처: URL
- [미국장 마감] (날짜) 지수·반도체 요약  · 출처: URL
- [거시] 금리/환율/업종 로테이션 사실  · 출처: URL

## 종목 뉴스 (정성)
### <종목명>
- [사실] (날짜) 헤드라인 — 한 줄 요약  · 출처: URL
(대상 종목이 없으면: "대상 종목 없음")

## 확인 불가
- <스크립트/검색으로 못 구한 항목을 그대로 남긴다 — 추정치로 채우지 않음>
```

- **호재/악재 라벨을 붙이지 않는다.** 사실과 출처만. 방향 해석은 위원회 몫이다.
- 모든 정량 수치의 진실원천은 스크립트다. 웹검색 수치와 충돌하면 스크립트가 이긴다(data-sources).

## 튜닝 상수

- `N = 5` — 위원회에 주입할 최근 영업일 수(오늘 제외 과거 N일). 회고가 조정할 수 있는 튜닝 값이며,
  변경은 사람 승인 후 이 상수를 고쳐 반영한다(trading-principles 무결성 4·5).

## 이 스킬이 하지 않는 것
- 매수/매도·목표가·비중 판단(→ 투자 위원회 B단계).
- 공시/DART 수집(제외 유지).
- 과거 브리핑 수정·삭제(append-only 박제).
