# analyze-company — 출력 템플릿 & 기록 스키마 상세

> SKILL.md 4·5단계에서 참조하는 상세 형식. 스킬 본문에는 골격만 두고,
> 실행 시점(출력을 만들 때)에만 이 파일을 읽어 형식을 확정한다 — 점진적 공개.

## 4단계 리포트 출력 형식

```
# 📊 OO 분석 리포트  (작성일: YYYY-MM-DD)

## 한 줄 요약
- (주가·뉴스·거시를 종합한 핵심 한두 문장)

## 1. 주가 흐름 (최근 1년)
- (stock-trend-researcher 결과 요약)

## 2. 회사 이슈 (최근 뉴스)
- (company-news-researcher 결과 요약)

## 3. 시장 환경 (한국 거시)
- (kr-macro-researcher 결과 요약)

## 4. 펀더멘털 (fundamentals.py)
- 매출/영업이익 추세, ROE·부채비율, PER/PBR·배당수익률 → 고/저평가 한 줄 해석
- 컨센서스: 투자의견 / 목표주가 (없으면 "커버리지 없음")

## 종합 해석
- 정성·정밀를 연결한 분석 (왜 이렇게 움직였나 / 지금 어떤 상황인가 / 싼가 비싼가)

## 매매 가격대 (참고용)
- 현재가(앵커): (quote.py 값)
- 진입가: (값) — 근거: (지지선 등)
- 목표(기대치): (값, +%) — 근거: (컨센서스/저항선)
- 손절가: (값, −%) — 근거: (지지선 하단/변동성)
- (재료 부족 시: "산출 불가 — 지지/저항·목표주가 데이터 없음")

## ⚠️ 유의
- 이 리포트는 웹검색 기반 참고 자료이며 투자 권유가 아니다. 매매·주문은 사람이 결정한다.
- 가격대는 관찰된 지지/저항·컨센서스에서 도출한 **참고 수준**이며 확정 예측이 아니다.
- 핵심 수치/주장에는 출처가 달려 있는지 확인할 것.
```

## 5단계 분석 기록 저장 — 스키마 상세

`save_analysis.py`에 넘길 JSON 스키마(상단 docstring 발췌):

```
{
  "company": "회사명",
  "date": "YYYY-MM-DD",
  "code": "종목코드",
  "price": {현재가},
  "entry": {진입가},
  "target": {목표가},
  "stop": {손절가},
  "atr_pct": {변동성},
  "status": "open",          // 회고가 hit_target|stopped|watching 으로 갱신
  "axes": {
    "trend": "주가 흐름 요약",
    "news": "뉴스 요약",
    "macro": "거시 요약",
    "fundamentals": "펀더멘털 요약",
    "support_resistance": "지지/저항 요약",
    "consensus": "컨센서스 요약"
  },
  "rationale": "매매 가격대 산출 근거 한 줄"
}
```

- 저장 위치: `data/analyses/YYYY-MM-DD-<회사>.md` (frontmatter 정량 + 본문 근거).
- 같은 날 같은 회사 재분석은 `-2`,`-3`…으로 **과거를 덮지 않는다**.
- 출력으로 `{"ref": "data/analyses/...", ...}`를 돌려준다. **recommend-stocks가 부른 경우 이 `ref`를 메인에 반환**.
- `axes`에는 정성 3축 요약뿐 아니라 **펀더멘털·지지저항·컨센서스 요약도 함께** 담는다(회고 복기용).
- `price`/`entry`/`target`/`stop`은 2.5·3.5단계 스크립트 값으로 채운다.
- 재료가 없어 가격대가 "산출 불가"여도 분석 자체는 기록한다(무엇을 못 구했는지가 회고 자료).
