# skill-stat

`PreToolUse:Skill` 훅(`.claude/hooks/log-skill-usage.sh`)이 쌓아 둔 호출 로그를 집계해 보여준다.

## 1. 입력

사용자 요청에서 **기간**과 **개수**를 뽑아 인자로 만든다.

| 사용자 표현 | 인자 |
|---|---|
| "이번 주 스킬 통계" | `--days 7` |
| "최근 한 달" | `--days 30` |
| "제일 많이 쓴 스킬 3개" | `--top 3` |
| 기간·개수 언급 없음 | (인자 없이) |

| 인자 | 의미 | 기본값 |
|---|---|---|
| `--days N` | 최근 N일만 집계 | 전체 기간 |
| `--top N` | 랭킹 상위 N개만 표시 | 15 |

## 2. 행동

```bash
bash .claude/skills/skill-stat/stats.sh [인자]
```

집계는 전적으로 이 스크립트가 한다. `.jsonl` 을 직접 읽어 세지 말 것.

## 3. 출력

스크립트 출력은 이미 사람이 읽을 형태로 완성되어 있다. **그대로 보여준다.**
표를 다시 그리거나 숫자를 재계산하지 말 것.

그 뒤에, 로그에서 실제로 읽히는 사실만 1~2줄로 덧붙인다.
(예: 특정 스킬 편중, 최근 며칠 사용 없음)

## 데이터

- 원본 로그: `.claude/data/skill-usage.jsonl` (append-only, 한 줄 = 호출 1건)
- 한 줄 형식: `{ts, skill, args, session_id, cwd}`
- `ts` 는 로컬 시각 + UTC 오프셋 (예: `2026-08-26T20:41:11+0900`)

집계 항목을 추가하고 싶으면 `stats.sh` 의 jq 표현식을 고친다. 원본 로그에
시각·세션·인자가 모두 남아 있으므로 시간대별·인자별 집계도 로그 재수집 없이 가능하다.

## 기록이 없다고 나올 때

1. `/hooks` 로 `PreToolUse` → `Skill` 훅이 등록되어 있는지 확인
2. `.claude/settings.json` 의 hooks 항목 확인
3. 훅은 **등록 이후의 호출부터** 기록한다. 과거 호출은 소급되지 않는다

## 주의

`/skill-stat` 호출 자체도 훅에 잡혀 `skill-stat` 으로 카운트된다.
의도된 동작이며, 통계 하단에 각주로 표시된다.
