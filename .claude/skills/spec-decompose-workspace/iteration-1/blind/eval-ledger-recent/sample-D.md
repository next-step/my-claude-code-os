# 인수기준 — 실패 원장 최근 7일 조회 스킬

요구사항: "실패 원장에서 최근 7일치만 뽑아 보여주는 스킬이 필요해."

## AC-1: 정상 조회 — 최근 7일 이내 기록만 표시
Given 실패 원장에 여러 건의 실패 기록이 날짜별로 존재할 때
When 스킬을 실행하면
Then 오늘 기준 최근 7일(오늘 포함) 이내에 발생한 실패 기록만 화면에 표시된다.

## AC-2: 경계값 제외 — 7일보다 오래된 기록은 제외
Given 실패 원장에 8일 전, 10일 전 등 7일을 초과한 기록이 포함되어 있을 때
When 스킬을 실행하면
Then 해당 오래된 기록은 결과 목록에 나타나지 않는다.

## AC-3: 경계값 포함 — 정확히 7일째 기록의 처리 기준 명시
Given 실패 원장에 정확히 "7일 전" 시각에 발생한 기록이 있을 때
When 스킬을 실행하면
Then 이 기록이 포함되는지 제외되는지가 명확히 정의되어 있고, 그 기준(예: 현재 시각 기준 168시간 이내, 또는 날짜 단위 비교)대로 일관되게 동작한다.

## AC-4: 원장이 비어 있는 경우
Given 실패 원장 파일은 존재하지만 기록이 하나도 없을 때
When 스킬을 실행하면
Then 오류 없이 "표시할 실패 기록이 없다"는 안내 메시지를 보여준다.

## AC-5: 최근 7일 내 기록이 하나도 없는 경우
Given 실패 원장에 기록은 있지만 전부 7일보다 오래된 경우
When 스킬을 실행하면
Then "최근 7일 내 실패 기록 없음"을 명확히 안내하고, 오래된 기록을 잘못 보여주지 않는다.

## AC-6: 원장 파일 자체가 없는 경우
Given 실패 원장 파일이 아직 생성되지 않았을 때
When 스킬을 실행하면
Then 오류로 중단되지 않고, 원장이 없다는 사실을 사용자에게 안내한다.

## AC-7: 정렬 순서
Given 최근 7일 이내 실패 기록이 여러 건일 때
When 결과를 표시하면
Then 최신 기록이 먼저 오도록 시간 역순으로 정렬되어 있다.

## AC-8: 표시 항목의 최소 구성
Given 최근 7일 이내 실패 기록이 존재할 때
When 결과를 표시하면
Then 각 기록마다 최소한 발생 시각, 실패 대상(예: 인수기준/테스트 이름), 실패 사유(또는 요약)를 확인할 수 있다.

## AC-9: 원본 원장 파일은 읽기 전용으로 다룬다
Given 스킬이 실행되는 동안
When 원장 파일을 조회하면
Then 원장 파일의 내용을 수정·삭제하지 않고 읽기만 한다.

## AC-10: 손상되거나 형식이 잘못된 기록에 대한 처리
Given 실패 원장 안에 날짜 형식이 잘못되었거나 필드가 누락된 기록이 섞여 있을 때
When 스킬을 실행하면
Then 전체 실행이 중단되지 않고, 해당 손상 기록은 건너뛰거나 별도로 표시하며 나머지 정상 기록은 정상적으로 보여준다.
