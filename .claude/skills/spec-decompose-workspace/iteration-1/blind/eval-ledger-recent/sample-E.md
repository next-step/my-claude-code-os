# 인수기준 — "실패 원장에서 최근 7일치만 뽑아 보여주는 스킬"

## AC-1: 정상 케이스 — 최근 7일 이내 항목만 표시
Given 실패 원장에 여러 날짜에 걸친 실패 기록이 있을 때
When 스킬을 실행하면
Then 실행 시점 기준 최근 7일(현재 시각 - 7일) 이내에 발생한 실패 항목만 결과에 표시된다.

## AC-2: 경계 밖 항목 제외
Given 원장에 8일 이상 지난 실패 기록이 포함되어 있을 때
When 스킬을 실행하면
Then 7일보다 오래된 항목은 결과 목록에 나타나지 않는다.

## AC-3: 경계값 처리 명시
Given 실패 발생 시각이 정확히 "현재 시각 - 7일" 경계에 걸쳐 있을 때
When 스킬을 실행하면
Then 포함/제외 기준(예: 7일 이내 = 현재 시각으로부터 168시간 이내, 이상은 제외)이 일관되게 적용된다.

## AC-4: 원장이 비어있거나 최근 7일간 실패가 없는 경우
Given 원장 파일은 존재하지만 최근 7일 이내 실패 기록이 하나도 없을 때
When 스킬을 실행하면
Then 에러 없이 "최근 7일간 실패 없음"과 같은 안내 메시지를 표시한다.

## AC-5: 원장 파일 자체가 없는 경우
Given 실패 원장 파일이 아예 존재하지 않을 때
When 스킬을 실행하면
Then 스킬은 에러로 죽지 않고, 원장이 없다는 사실을 사용자에게 알린다.

## AC-6: 정렬 순서
Given 최근 7일 이내 실패 항목이 여러 건 있을 때
When 결과를 표시하면
Then 항목은 발생 시각 기준 최신순(내림차순)으로 정렬되어 표시된다.

## AC-7: 표시 항목의 최소 구성
Given 최근 7일 이내 실패 항목이 하나 이상 있을 때
When 결과를 표시하면
Then 각 항목은 최소한 (1) 발생 시각, (2) 어떤 인수기준(AC) 또는 테스트가 실패했는지, (3) 실패 사유/메시지를 포함한다.

## AC-8: 읽기 전용 — 원장 파일을 수정하지 않음
Given 스킬이 원장 파일을 읽을 때
When 최근 7일치를 추출·표시하는 동안
Then 원장 파일의 내용은 변경되지 않는다(기록은 훅의 몫, 이 스킬은 읽기만 한다).

## AC-9: 원장 파일 형식 손상 시 처리
Given 원장 파일이 예상 형식(JSON 등)과 다르거나 파싱할 수 없을 때
When 스킬을 실행하면
Then 스킬은 원인을 알 수 있는 에러 메시지를 표시하고 중단하며, 잘못된 값으로 조용히 넘어가지 않는다.

## AC-10: 반복 실패 여부는 이번 범위에서 제외
Given 같은 인수기준이 최근 7일 내에 여러 번 반복 실패했을 때
When 결과를 표시하면
Then 이번 스킬은 "최근 7일치 표시"까지만 책임지며, 반복 실패 빈도 분석·경고는 범위 밖으로 명시한다(필요하면 별도 스킬로 분리).

---

## 범위 밖 (Out of scope)
- 실패 원장 자체를 생성·기록하는 기능(원장에 실패를 추가하는 것은 훅의 몫).
- 7일 외 다른 기간(예: 30일, 전체 기간) 조회 옵션 — 이번 요구사항은 "최근 7일"로 고정.
- 같은 AC의 반복 실패 빈도·트렌드 분석.
- 원장 항목을 삭제하거나 원장 파일을 수정하는 기능.

## 미해결 가정
- "최근 7일"의 기준 시점은 스킬 실행 시각(현재 시각)으로 가정했다 — 자정 기준 캘린더 날짜(7일 전 자정부터)일 수도 있어 확인이 필요하다.
- 원장 파일의 정확한 스키마(필드명, 시간 포맷)는 확인하지 못했다 — 실제 구현 전 원장 파일 구조를 먼저 확인해야 한다.
- 타임존 처리(로컬 시간 vs UTC)는 명시된 바 없어 가정으로 남겨둔다.
