# Serve — 로컬 기동과 사람 확인

## Overview

대상 프로젝트를 로컬에 띄워 **사람이 직접 API를 호출해볼 수 있는 상태**로 만든다.
**에이전트 없음 — 메인이 직접 한다.** 기동 실패 트러블슈팅은 사람에게 물어야
풀리는 것이 절반이고(VPN·포트·secret·런타임), 산출물이 반환 텍스트가 아니라
**살아있는 프로세스**라서 위임하면 상태 인계 비용이 이득을 넘는다.

`/experiment` 9단계(인계·판정)를 **수치 밖에서** 보강하는 자리다. 측정 표가
못 잡는 것을 눈으로 확인해 채택 판단의 재료로 쓴다.

## 절차

| # | 담당 | 단계 |
|---|------|------|
| 1 | 🟢 메인 | **컨텍스트 로드** — `private/project.md`의 경로·실행법(SSOT). 없으면 사용자에게 질문. 명령을 이 스킬에 복제하지 않는다 |
| 2 | 🔵 사람 | **대상·방식 확인** — 어느 브랜치 상태로 띄울지 + 기동 방식. 메인이 추천을 근거와 함께 제시하고 확인받는다 (아래 선택 기준) |
| 3 | 🟢 메인 | **사전 점검·기동** — 포트 점유, `.env`/secret 필요 여부, (Docker면) 런타임·VPN. 백그라운드 기동 후 healthcheck로 확인 |
| 4 | 🟢 메인 | **인계** — 엔드포인트, 호출 예시 1건, 로그 보는 법, 정리 명령을 사용자에게 전달 |
| 5 | 🔵 사람 | **직접 호출·확인** — 응답이 이상하면 3단계로 돌아가 로그 확인·재기동 |
| 6 | 🟢 메인 | **정리** — 프로세스·컨테이너 종료·삭제. 계속 쓰겠다면 정리 명령을 남긴다 |

## 기동 방식 선택 기준 (2단계)

| 목적 | 방식 | 근거 |
|---|---|---|
| 실험 로직을 API로 확인 (기본) | venv 직접 기동 | 즉시 뜬다 |
| 배포 환경과의 동일성 확인 | Docker amd64 | 빌드에 수 분 (에뮬레이션 + 모델 다운로드) |

Docker 절차는 대상 저장소의 로컬 컨테이너 가이드가 SSOT — 문서 경로는
`private/project.md`에 있다. 참조만 하고 옮겨 적지 않는다.

## 불변 규칙

1. **원격 접근 금지** — `git push`, `docker login`, `docker push`, 사내 레지스트리·
   배포 플랫폼 접근을 하지 않는다. 정식 반영은 사용자 직접 (ADR-0017 ·
   `private/project.md` "실험 범위 밖" 절).
2. **secret을 명령줄에 노출하지 않는다** — Docker는 `--env-file .env`만 쓴다.
   `-e <이름>=<값>` 형태는 값이 대화 기록에 영구히 남으므로 금지. 로그를 인용할 때
   secret이 찍힌 줄은 옮기지 않는다.
3. **코드 수정 금지** — 기동만 담당한다. 응답이 틀려 보여도 고치지 않는다.
   수정은 `/experiment`(applier) 경로.
4. **커밋 금지 + 체크아웃 안전** — 브랜치를 바꾸기 전 워킹 트리가 더티면 먼저
   알리고 사용자 판단을 구한다. 사용자 작업을 stash·commit으로 임의 처리하지 않는다.
5. **정리 없이 끝내지 않는다** — 6단계를 건너뛰면 다음 기동이 포트 충돌로 실패한다.
6. **이 문서에 대상 프로젝트 고유명을 적지 않는다** — 저장소명·파일명·환경변수명·
   인프라 이름은 `private/project.md`가 SSOT다. 이 스킬은 공유 파일이라
   `step*` 브랜치로 나간다 (ADR-0012 · ADR-0015).

## Common Mistakes

| 실수 | 해결 |
|---|---|
| 색상 로직 확인이 목적인데 Docker로 빌드 | venv 기동이 즉시 — Docker는 배포 환경 동일성이 목적일 때만 |
| secret을 `-e`로 주입 | `--env-file .env` |
| 기동 로그 전문을 대화에 붙임 | 부팅 성공 여부 + 에러 줄만 |
| 응답이 이상해서 코드를 고침 | 기동만 담당 — 수정은 `/experiment` |
| 정리 없이 세션 종료 | 6단계 필수 |
