# 컨텍스트를 바꿀 때는 재고, 효과를 주장할 때는 팔로 가른다

컨텍스트 체계(지침·스킬 설명·MCP)는 **매 세션 세금**이다. 늘리거나 줄일 때 감으로 판단하지 않는다.

- **바꾸기 전후로 잰다.** `summarizeBudget()`(`.claude/lib/context-map.js`)이 기준이다. 호출부마다 덧셈을 다시 하면 사람마다 다른 수치를 말하게 된다. 잰 값은 `docs/context-budget.md`에 남긴다.
- **"이게 효과 있다"고 말하려면 팔로 갈라 돌린다.** `context-ab` 스킬. 팔은 지침 구성만 다르고 나머지는 같아야 한다. 팔 사본에서 `.git`과 훅을 빼는 이유는 통제다 — gitStatus(최근 커밋)는 서브에이전트까지 상속돼 지침 대신 커밋 로그를 비교하게 만든다.
- **자동 채점 결과를 믿지 않는다.** 이 저장소에서 세 실험 연속으로 채점 기준이 대상보다 부정확했다. 수치가 이상하면 루브릭을 먼저 의심한다.
- **실험 결과는 커밋하지 않고 설정을 커밋한다.** 재현을 가능하게 하는 것은 산출물이 아니라 팔 정의다.

근거: `docs/context-ab-test.md`(실험 1~3), `docs/context-budget.md`.
