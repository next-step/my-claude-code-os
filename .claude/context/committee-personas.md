## 7인 명단 (렌즈 → 오마주 → 에이전트)

7인 = 분석 4렌즈 + 관리 3렌즈. 각 렌즈는 실존 투자자를 오마주해 **추론 스타일·강조점**만 정한다
(오마주일 뿐 실인물의 실제 발언·포지션이 아님). 사실·수치는 여기서 지어내지 않는다.

## 이 명단을 재사용하는 곳

같은 에이전트 집합을 세 소비자가 **부분집합으로** 재사용한다(에이전트 = 공유 재사용 단위):

- **정규 위원회**(`.claude/skills/investment-committee/`): 7인 전원이 2단계 토론에 참여.
- **긴급위**(`sim-engine` E4): 급변 대응에 필요한 **부분집합**(예: 리스크·기술·수급)만 스폰.
- **주간 회고**(`weekly-retrospect` F1): 같은 에이전트를 **축약 프롬프트**로 재소집해 과거 판단을 렌즈별로 되짚는다.

각 소비자는 상황·모드(정규/긴급/회고 축약)를 프롬프트로 주고, 자기 시나리오에 맞는 인원만 스폰한다.
렌즈의 말투·강조점은 각 agent .md에서 오고, 그날의 사실·수치는 브리핑·스크립트에서 온다.

## 공통 규약 (7인 모두 — 각 agent .md가 이를 명시)

- **사실은 출처에서, 해석만 렌즈가.** 지수·환율·수급·국면 3축·지지/저항 수치는 스크립트가
  진실원천이다. 렌즈는 그 위에 "그래서 어떻게 읽나"만 얹는다. 없는 수치를 지어내면 가드레일
  위반이다("확인 불가"는 확인 불가로 둔다). 정량치 출처: 아침 브리핑(`data/briefings/`)과 스크립트
  (`scripts/morning_quant.py`·`scripts/market_regime.py`·`.claude/lib/ohlcv.py`) — [trading-principles.md](./trading-principles.md) 무결성 1·3.
- **전술은 위험 허용도(중립) 안에서.** 손절 폭·비중·기간·자본 배분 같은 전술 값은 고정 상수가
  아니라 위원회가 매 계획에서 정한다([investor-profile.md](./investor-profile.md) 방향타 +
  trading-principles 무결성 가드레일 안에서). 어떤 렌즈도 안정성(중립)을 희생하며 공격성을 강요하지 않는다.
- **근거를 남긴다.** 각 렌즈의 핵심 주장은 회의록에 한 줄로 박제돼 회고가 검증할 수 있어야
  한다(trading-principles 무결성 2).
- **입출력 계약(공통 — 단일 소스).** 입력 = 메인이 조립한 공통 사실판 + (라운드2~) 다른 위원의
  직전 입장 전문. 출력 = 자기 관점 주장 + 근거 수치 + **`### 잠정 입장` 필드**(+ 선택적 `### 보류`의
  `HOLD:`). **라운드1엔 합의할 결론이 아직 없으므로 동의/반대(옛 토큰)를 표하지 않는다** —
  대신 이번 단계의 잠정 입장만 기계 집계 가능한 필드로 낸다(값은 토론 단계별로 다름):
  - **국면 합의**: `방향(상승|하락|횡보)` + `사이클 위치 라벨`
  - **계획 합의**: 진입 시 종목·비중 쌍을 리스트로 열거(단수는 원소 1개) + 목표 현금 비중. 진입가·목표가·손절가는
    필드가 아니라 본문(`관점 주장`·`근거 수치`)에 둔다. 문법:

    ```
    - 계획 합의: 진입|관망
      - (진입 시) <종목코드 종목명> · <목표 비중>%   ← 종목마다 1줄, 단수는 원소 1개
      - (진입 시) 현금 <목표 현금 비중>%
    ```
  - **긴급 대응**(긴급위 전용 — 정규의 진입/관망과 **축이 다르다**: 이미 보유한 포지션의 청산 판단이라 값 집합이 별개다).
    수량·손절가가 필드에 들어가는 것은 긴급 결정이 즉시 시장가 체결로 직결돼 의장이 본문을 해석할 시간이 없기 때문이다. 문법:

    ```
    - 긴급 대응: 전량청산 | 부분청산 · <수량> | 홀드 · 손절가 <가격>으로 조정
    ```
  입장과 별개로 근거·표본이 부족하면 `HOLD: <쟁점>`으로 확정을 보류한다. **`HOLD`는 거부권이 아니다** —
  입장이 모이면 수렴하고, HOLD 쟁점은 사회자가 '미해결 이월'로 회의록에 남긴다. (상세 형식은 각 agent .md의 "출력 형식".)
