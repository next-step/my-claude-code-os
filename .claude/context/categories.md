# 분류 규칙 정본 — 할일 카테고리 6종

> **이 파일의 역할**: 할일 `category`의 유일한 출처. 지금까지 이 규칙은 세 곳
> (capture SKILL Step 2 표 · `_shared/classifier-agent.md` · `_shared/classify.sh`)에
> 복제돼 있었다. 이제 **이 파일이 정본**이고, 나머지는 이 파일을 참조하거나(md) 이 파일의
> 코드 표현(bash)으로 취급한다. 규칙을 바꾸면 이 파일을 먼저 고친다.

## 카테고리 정의

| 카테고리 | 해당 키워드 예시 |
|---------|---------------|
| **스터디** | 강의, 책, 자격증, 세미나, 공부, 학습, 과제, 읽기 |
| **업무** | 미팅, 리포트, 데드라인, 리뷰, 회의, PR, 발표, 제안서 |
| **일상** | 장보기, 청소, 약속, 취미, 쇼핑, 요리, 빨래 |
| **건강** | 병원, 운동, 약, 검진, 헬스, 산책, 수면 |
| **금융** | 납부, 이체, 세금, 보험, 카드, 환전, 저축 |
| **기타** | 위 카테고리에 해당하지 않는 것 |

`category` 필드에는 이 6개 값 중 **하나의 한글 단어**만 들어간다.
다른 값을 쓰지 않는다 → 스키마는 [`data-model.md`](./data-model.md).

## 분류 규칙

1. **가장 가까운 카테고리 하나**를 고른다.
2. **두 카테고리에 걸치면 더 구체적인 쪽**을 고른다.
   (예: "헬스장 등록비 납부" → 금융이 아니라 **건강**)
3. **확실하지 않으면 `기타`**.
4. 분류 결과에 **설명을 덧붙이지 않는다** — 카테고리 이름 한 단어만.

## 이 규칙을 쓰는 세 표현 (모두 동기화 대상)

같은 규칙이 실행 경로에 따라 세 가지로 나타난다. 하나를 바꾸면 셋을 함께 갱신한다.

| 표현 | 위치 | 언제 쓰나 |
|------|------|-----------|
| **이 파일** | `context/categories.md` | 정본 — 규칙의 기준 |
| 메인 인라인 분류 | `capture/SKILL.md` Step 2 | 대화형 `/capture` (메인 모델이 표 보고 직접) |
| 서브에이전트 프롬프트 | `_shared/classifier-agent.md` | Agent 도구로 분류 위임 시 |
| bash 사전 분류 | `_shared/classify.sh` | 텔레그램 경로 (모델 없이 ~0.03s) |

> **왜 bash 표현이 따로 있나**: 텔레그램 경로는 `claude -p` 콜드 스타트(~10s)를 우회해야
> 노티스가 2초 안에 나간다. 그래서 모델 대신 사전으로 분류한다. 대표 키워드는 정확하지만
> 한 글자 모호어(예: "약")는 놓칠 수 있는 의도된 트레이드오프이며, 나중에 `/plan`에서
> 카테고리를 조정할 수 있다. 설계 배경은 [`design-principles.md`](./design-principles.md).
