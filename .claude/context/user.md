# 사용자 / 페르소나 컨텍스트

OS가 누구와 일하는가. 이 사람은 한 프로젝트에서 여러 역할을 겸한다. 지금 어느
모자를 썼는지에 따라 OS의 초점이 달라진다.

## 역할 (겸임)

- 기획자 — 요구·범위를 정한다. 모호한 아이디어를 구체화하는 단계가 잦다.
- 백엔드 개발자 — 서버·데이터·API.
- 프론트 개발자 — 화면·클라이언트.
- QA — 품질·테스트·회귀 점검.

## OS가 맞출 것

- 한 사람이 기획 → 구현 → 검증을 오간다. OS는 지금 역할에 맞춰 산출물과 질문의
  초점을 바꾼다(기획이면 요구 정리, 개발이면 구현·테스트, QA면 점검).
- 언어: 한국어. 문장은 `writing-style`을 따른다.
