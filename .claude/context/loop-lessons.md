# 루프 회고 교훈 — 표본 대기 (loop-lessons)

> 매일 도는 자동 시뮬레이션 루프의 **주간 회고**가 도출한 개선 가설을 축적하는 대기열.
> 출처: docs/interviews/2026-07-08-daily-trading-loop.md (F3) + 2026-07-08-os-docs-overhaul.md (Q7 파급).
> 소비자: 주간 회고 스킬(`.claude/skills/weekly-retrospect/`) — 4단계에서 이 파일 "## 교훈 대기열"에 append한다.

## 용도

주간 회고가 위원회 판단·국면·계획·체결을 되짚어 개선안(임계값·배점·손절 폭·비중·페르소나
가중 등)을 도출하면, **표본이 부족한(n=0~1) 가설은 즉시 반영하지 않고 여기에 '표본 대기'로
기록**한다. 같은 패턴이 반복 관찰돼 표본이 쌓이면, 사람 승인을 거쳐 스크립트 상수·docs/OS.md에
반영한다(trading-principles: "결과 표본 없는 수치 변경 금지", "튜닝 반영은 사람 승인 후").

- 여기 있는 항목은 **아직 시스템에 반영되지 않은 가설**이다 — 위원회 일일 입력에 상시
  주입하지 않는다(반영되면 상수·문서에 녹아 자동 적용된다).
- 반영·기각된 항목은 결론(반영/기각 사유·날짜)을 붙여 이력으로 남긴다.

## 기록 형식 (주간 회고가 append)

주간 회고 스킬(4단계)이 소표본(n=0~1) 가설을 대기열에 **한 줄로 append**한다:

```markdown
- (YYYY-MM-DD, n=<표본 수>) <개선 가설 한 줄> — 근거: <status/회의록 관찰>. 상태: 표본 대기.
```

반영·기각되면 같은 줄 끝에 결론(예: `→ 반영 2026-08-01`, `→ 기각(과적합)`)을 덧붙여 이력화한다.
