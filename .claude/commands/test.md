`$ARGUMENTS`는 작업 폴더(`$DIR`)다. `<프로젝트>/tasks/NNN-작업명` 형태라는 전제에서 프로젝트 루트(`$PROJECT`)를 도출한다.

## 원칙

- **spec.md가 유일한 요구사항 소스다.** 테스트는 정책의 번역이다 — 정책에 없는 요구를 테스트로 지어내지 않는다.
- **구현하지 않는다.** `$PROJECT/src/`(구현 코드)를 한 줄도 수정하지 않는다.
- **테스트는 시작 시점에 실패해야 한다 (Red).** 실패를 실행으로 확인해야 종료할 수 있다.

## 실행 순서

### 1단계: 게이트

`$DIR/spec.md`를 읽는다.

- 파일이 없으면 "해당 폴더에 spec.md가 없습니다. 먼저 /spec으로 작성하세요."라고 출력하고 종료한다.
- `status: approved`가 아니면(필드가 없거나 `draft`인 경우 포함) "spec.md가 아직 승인되지 않았습니다 (status: {값}). /spec-review와 승인을 먼저 진행하세요."라고 출력하고 종료한다.
- 본문에 `결정 필요(미결정)` 항목이 남아 있으면 멈추고, 어떤 결정이 필요한지 나열한 뒤 종료한다.

### 2단계: 테스트 환경 파악

언어와 테스트 러너를 감지한다 (Python: pytest, 없으면 unittest / TypeScript: 프로젝트에 설정된 러너 / 그 외: 언어 표준 관례). 기존 테스트 디렉토리가 있으면 그 관례를 따르고, 없으면 `$PROJECT/tests/`를 만든다.

### 3단계: 정책별 테스트 작성

각 정책(P-…)마다 최소 3종을 만든다:

1. **예시 재현** — spec의 `예시`를 그대로 테스트로 옮긴 것 1개. 숫자와 입출력을 바꾸지 않는다.
2. **정상 경로** — 규칙의 대표 사용 1개 이상.
3. **엣지** — 경계값, 빈 입력/파일 없음, 없는 대상, 중복 실행 중 해당되는 것 1개 이상.

**이름 규칙:** `test_P{작업번호}_{순번}_{설명}` (예: `test_P002_1_priority_saved`). 이 이름이 정책 ID와 테스트를 잇는 유일한 연결이므로 반드시 지킨다.

**자기 점검:** 정책마다 "이 테스트들을 전부 통과하면서도 규칙을 위반하는 구현이 가능한가?"를 자문한다. 가능하면 그 구멍을 막는 테스트를 추가한다.

### 4단계: test-plan.md 작성

`$DIR/test-plan.md`에 매핑을 기록한다. 최상단 프론트매터:

```yaml
---
created: YYYY-MM-DD
policies: {정책 수}
tests: {테스트 수}
---
```

본문은 매핑 표 하나만 포함한다:

```markdown
| 정책 ID | 테스트 이름 | 종류 | 시작 상태 |
|---------|------------|------|----------|
| P-002-1 | test_P002_1_priority_saved | 예시 | red |
```

종류는 `예시`/`정상`/`엣지`, 시작 상태는 5단계에서 채운다.

### 5단계: Red 확인

작성한 테스트 전체를 실행한다. **실패(Red)가 정상 상태다.**

- 각 테스트의 결과를 test-plan.md의 `시작 상태` 열에 기록한다 (`red` / `기존충족`).
- **통과하는 테스트가 있으면** 원인을 판별한다: (a) 기존 코드가 이미 그 정책을 충족한다 → `기존충족`으로 표기하고 회귀 방지용으로 유지한다. (b) 테스트가 아무것도 검증하지 않는다(동어반복) → 테스트를 고쳐 red로 만든다.
- 실행 자체가 깨지는 에러(문법, import 실패 등)는 고친다 — red는 "단언이 실패"하는 상태여야지 "테스트가 망가진" 상태면 안 된다. 단, 미구현 기능 호출로 인한 실패는 정상 red다.

### 6단계: 멈춤

**구현하지 않는다.** 사용자에게 다음을 보고하고 종료한다:

- 정책 N개 → 테스트 M개 (red K개, 기존충족 J개), test-plan.md 경로
- 안내 문구: "다음으로 `/impl <같은 폴더>`를 실행하세요. 구현은 이 테스트들을 수정할 수 없습니다 — 테스트가 전부 통과하면 정책이 충족된 것입니다."
