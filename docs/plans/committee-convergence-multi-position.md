# 위원회 수렴 판정·비중 확정 오케스트레이션

## 목표
의장(메인 스킬)이 복수 종목 진입 주장을 **결정론적으로 집계·판정**하게 된다. 끝나면 "무엇을
살지"는 종목 집합 일치로 수렴하고, "얼마나 살지"는 리스크 봉투 안에서 의장이 확정하며,
5R 미합의·봉투 부재 같은 엣지케이스에 지어낼 여지가 없다.

## 전제
선행 항목 [committee-position-field-contract](./committee-position-field-contract.md)가 끝나
에이전트가 리스트 문법으로 응답해야 이 항목의 집계 로직이 의미를 갖는다. **순차 진행.**

## 범위
- 포함 (investment-committee):
  - **수렴 판정(Q5)**: 계획 합의는 **진입 종목 코드 집합 일치**로 판정. 비중 차이는 수렴을 막지 않는다.
    진입·관망이 갈리면 미수렴(Q4 — 기존 문구 유지).
  - **비중 확정(Q6)**: 리스크 렌즈가 낸 **봉투**(총 리스크 캡·종목당 명목 하드캡·현금 하한·손절 산식)를
    제약으로, 그 안에서 의장이 근거 우위로 종목별 비중·목표 현금 비중을 확정한다.
  - **봉투 부재 폴백(Q8)**: 집합이 수렴했는데 봉투가 없으면 의장이 `committee-risk`를 **한 번 더 스폰해
    봉투만 받는다**(그 렌즈의 진입/관망 입장과 무관). 침묵이 거부권이 되지 않게 한다.
  - **5R 미합의(Q7)**: 종목 집합이 안 모이면 **교집합만 부분 채택**, 갈린 종목은 관망 + '미해결 이월'.
    **교집합이 비면 전체 관망.** 이 규칙은 **계획 합의 단계에 한해** 기존 Q16(의장 근거 우위)을 대체하고,
    국면 합의 단계에는 Q16이 그대로 남는다.
  - **회의록 궤적(Q10)**: 렌즈별 궤적을 **종목 집합 변화만** 적는다(예: `{069500, 132030} → {069500} · 금 빼기로 선회`).
    비중은 궤적에 적지 않고, 확정 근거는 '계획 결정' 섹션에 남긴다.
- 포함 (sim-engine):
  - **긴급위 즉시 종합(Q9)**: 필드 값이 갈리면 의장이 **그 분 안에 즉시 종합**한다(관통 대기 없음).
    값 집합 자체의 정의는 선행 항목이 소유하고, 여기선 **판정·종합 규칙**만 쓴다.
- 포함 (docs/OS.md):
  - B단계 서술의 "메인이 **잠정 입장 필드 일치**로 수렴을 판정한다" 문장이 복수 종목에서도 참이 되도록
    **종목 집합 일치**임을 명시하고, 5R 미합의 시 교집합 채택을 한 줄 반영한다(구조적 결정이라 갱신 대상).
- 제외:
  - 필드 문법·긴급위 값 집합 정의 — 선행 항목.
  - 투자계획서 스키마 — 이미 종목별 복수 행 지원, 변경 불필요.
  - 국면 합의 필드·수렴 규칙 — 변경 없음.

## 구현 단계
1. `investment-committee/SKILL.md`의 "동적 수렴 루프 → 수렴 판정" 항목에서, 계획 합의의 수렴 조건을
   **종목 집합 일치**로 명시한다(현행 "필드가 하나로 모인다"가 복수 종목에서 모호함을 해소).
2. 같은 SKILL의 `3-2. 계획 합의` 절에 **비중 확정 규칙(Q6)**과 **봉투 부재 폴백(Q8)**을 추가한다.
   봉투의 구성 요소(총 리스크 캡·명목 하드캡·현금 하한·손절 산식)를 명시하되, **값은 고정하지 않는다**
   (전술은 위원회 일임 — `investor-profile` 방향타).
3. 같은 SKILL의 5R 미합의 처리에 **교집합 부분 채택(Q7)**을 쓰고, 국면 합의에는 Q16이 유지됨을 구분해 적는다.
4. 같은 SKILL의 회의록 스키마에서 '렌즈별 입장 궤적'을 **종목 집합 변화 표기(Q10)**로 고친다.
5. `sim-engine/SKILL.md`의 4단계(긴급위)에 **필드 값 갈릴 시 의장 즉시 종합** 규칙을 명시한다.
6. `docs/OS.md` B단계 서술에 종목 집합 수렴·교집합 채택을 반영한다(이유 포함, OS.md 작성 규칙 준수).
7. `python3 scripts/check_context.py` PASS 확인.

## 검증
- 문서 규약이라 스크립트 검증 대상이 아니다. 대신 **반례 대조**로 확인한다:
  - 집합 `{A,B}` vs `{A}` → 미수렴으로 읽히는가.
  - 집합 같고 비중 8/4 vs 5/7 → 수렴으로 읽히고, 비중은 봉투 안에서 의장이 정하는가.
  - 5R 미합의에 교집합이 비면 전체 관망으로 읽히는가.
  - 리스크가 관망이라 봉투를 안 냈을 때 재스폰 경로가 명시돼 있는가.
- `check_context.py` PASS 유지.
