# 위원회 오케스트레이션 전환 (라운드1 발산 / 라운드2+ 수렴)

## 목표
동적 수렴 루프를 **"라운드1 발산 → 의장이 쟁점을 정리 → 라운드2부터 좁혀 감"** 흐름으로 재작성한다.
의장은 결론 초안을 내밀지 않고(앵커링 방지), 수렴은 **잠정 입장 필드의 일치**로 판정한다.
회의록은 결론뿐 아니라 **의견이 움직인 궤적**을 남긴다.

## 배경 (왜)
기존 루프(Q4)는 라운드1에서 토큰을 받아 "이의자만" 재소집했다. 그런데 라운드1엔 동의할 대상이
없고, 다수파가 소수의 반박을 보고 재고할 경로도 닫혀 있었다. 스모크에서 **다수파의 의견 변화가
수렴의 실제 동력**이었다(기술 렌즈가 회의론자 지적을 받아 근거를 구조값으로 교정, 수급·거시가
진입에서 관망으로 자진 철회). Q17이 Q4의 '비용 절약(이의자만 재소집)' 규칙을 의도적으로 뒤집는다.

## 범위
- 포함 (`investment-committee/SKILL.md` 3단계 "동적 수렴 루프" 재작성):
  - **라운드1 = 발산 전용.** 7인 전원 병렬 소집, 잠정 입장 필드 + 근거만 받는다(동의/반대 없음).
  - **라운드2~ = 수렴.** 의장이 **쟁점 정리**(무엇으로 갈렸는가)만 올리고 **7인 전원 재소집**하며,
    다른 위원의 직전 입장 전문을 함께 넘긴다. 결론 초안을 내밀지 않는다.
  - **수렴 판정**: 잠정 입장 필드가 하나로 모임, **또는** 직전 대비 새 실질 반박 없음.
  - **HOLD 처리**: 입장이 모였는데 `HOLD`가 있으면 **수렴으로 보고 실행**하되, HOLD 쟁점을
    회의록의 '미해결 이월'로 박제한다(HOLD는 거부권이 아니다).
  - **라운드1 만장일치 예외**: 즉시 종료하지 않고 라운드2를 한 번 돌려 **회의론자가 만장일치 자체를
    반대신문**하게 한 뒤 판정한다.
  - **상한 5R 유지**(발산 1R + 수렴 4R). 5R까지 입장이 갈리면 **의장이 근거 우위로 결론**하고
    소수 의견·HOLD를 모두 회의록에 남긴다.
  - **회의록 스키마 확장**: '렌즈별 핵심 주장'을 **`R1 입장 → 최종 입장` + 바뀐 이유** 궤적으로.
  - `sim-engine/SKILL.md` 긴급위(E4) 문구를 새 계약에 맞춤 — 긴급위는 성격상 **라운드1 발산**과
    같으므로 잠정 입장 필드 + HOLD를 받아 의장이 즉시 종합한다(수렴 루프 없음은 그대로).
- 제외:
  - 에이전트 출력 계약(선행 항목이 소유). 이 항목은 그 계약을 **소비**한다.
  - `docs/OS.md` 62행 — plan-todo 단계에서 이미 갱신 완료(설계 문서는 결정 확정 시 반영).
  - `weekly-retrospect/SKILL.md` — 토큰 언급이 없어 수정 불필요(에이전트 md 변경으로 자동 반영).
  - 2단계 순차 구조(국면→계획)·공통 사실판 조립·상한 값 — 변경 없음.

## 구현 단계
1. 선행 항목이 확정한 `committee-personas.md` 입출력 계약을 읽어 필드·HOLD 문법을 그대로 따른다.
2. `investment-committee/SKILL.md`의 "동적 수렴 루프" 절을 재작성한다:
   라운드1(발산) → 의장의 쟁점 정리 → 라운드2~5(전원 재소집·수렴) → 수렴 판정 → 미합의 처리.
3. 같은 SKILL의 회의록 스키마에서 '렌즈별 핵심 주장'을 입장 변화 궤적 형식으로 확장한다.
4. 3-1(국면 합의)·3-2(계획 합의) 절의 "라운드1은 전원 병렬 소집 권장" 문구를 새 프로토콜 용어로
   정리하고, 단계별 잠정 입장 필드 값(국면=방향+라벨, 계획=진입/관망+종목·비중)을 명시한다.
5. `sim-engine/SKILL.md` E4의 "개회 주장(AGREE/DISSENT)을 받고" 문구를 새 계약으로 교체한다.
6. SKILL·에이전트·personas 셋의 필드 이름·HOLD 문법이 정확히 일치하는지 대조한다.
