# 휴장일 게이트 (거래소 달력 판정)

## 목표
무인 체인이 돌기 전에 **오늘이 개장일인지** 결정론적으로 판정하고, 휴장일이면 클로드를 한 번도
부르지 않고 끝낸다. 판정 자체가 실패하더라도 루프의 방어(손절 감시)는 멈추지 않는다.

## 배경
cron의 `1-5`는 주말만 거른다. 설날·추석·임시공휴일에도 브리핑·위원회가 돌면 **거래가 없던 날의
회의록·계획서가 append 로그에 박제돼 주간 회고(F)의 표본을 오염시킨다**(Q5 — 토큰 절약이 아니라
기록 무결성 문제다).

## 범위
- 포함:
  - `exchange_calendars`(오프라인 XKRX 달력) 의존성 도입(Q12). 저장소 첫 외부 파이썬 의존성이라
    `requirements.txt`를 신설한다.
  - 개장 여부 판정 스크립트 — 종료 코드로 개장/휴장/판정불가를 구분해 셸이 분기할 수 있게 한다.
  - **판정 불가 시 '개장'으로 간주**(Q18). 실패 사실은 호출한 셸이 푸시하도록 stdout/stderr로 알린다.
- 제외:
  - 장중 시간대 판정(09:00~15:30) — 이미 `fill_engine.py`의 `MARKET_OPEN`/`MARKET_CLOSE`가 소유.
  - 셸 스크립트에서 이 게이트를 실제로 호출하는 배선(별도 항목).

## 구현 단계
1. `requirements.txt` 신설, `exchange_calendars` 추가. 설치 방법을 README나 스크립트 주석에 한 줄 남긴다.
2. `scripts/market_calendar.py` 신설 — `XKRX` 달력으로 오늘(또는 `--date`)이 거래일인지 판정.
   - 개장 → 종료 코드 0
   - 휴장 → 종료 코드 1
   - 판정 불가(임포트·조회 실패) → 종료 코드 2 + stderr에 사유. **호출자는 2를 '개장'으로 다룬다**(Q18).
3. `--date YYYY-MM-DD` 옵션으로 과거·미래 날짜를 확인할 수 있게 해 검증을 쉽게 만든다.

## 건드릴 파일
- `requirements.txt` — 신설(첫 외부 의존성).
- `scripts/market_calendar.py` — 신설. 설계 근거 ref 주석 포함.

## 검증
- 알려진 휴장일(예: 신정·설 연휴)과 평일을 `--date`로 넣어 종료 코드가 갈리는지 확인.
- 라이브러리를 일부러 못 찾게 만든 상태에서 종료 코드 2와 stderr 메시지가 나오는지 확인.

## 열린 세부 (구현 시 확정)
- `exchange_calendars`가 임시공휴일을 반영 못 한 날의 처리 — 지금은 '빈 기록이 남는다'를 감수한다
  (Q12의 대가로 명시적으로 수용). 실제로 문제가 되면 주간 회고가 표본을 보고 되살린다.
