# 모의 시뮬레이션 엔진 스킬 (E)

## 목표
장중 09:00~15:30 동안 위원회 계획서대로 모의 체결하고 포트폴리오 상태를 갱신하며, 급변 시
긴급 위원회를 자동 소집하는 엔진. 끝나면 계획서의 진입 대기 주문이 실시간으로 체결·기록되고,
포트폴리오가 '지금 상태'의 진실원천이 된다.

## 범위
- 포함:
  - **데이터 소스(E2·Q19)**: 09:00~15:30 라이브 1분 폴링(네이버 현재가). 폴링 간격·차단 회피(지터·재시도)는 구현 시 확정.
  - **체결 로직(E1)**: 한 틱 관통 시 체결 판정(매수 지정가 −1틱, 매도 +1틱 관통 — 보수적 확인), **체결가는 지정가로 기록**(Q22). 틱은 **KRX 가격대별 호가단위 스크립트**로 산출(Q23).
  - **수량(Q25)**: 위원회(계획서)가 정한 주문 수량대로 집행만. 엔진은 수량 계산 안 함. '못 사는 종목' 엣지는 위원회 단계에서 소멸.
  - **포트폴리오 상태(E3·Q20)**: 상태파일 1개 제자리 갱신(보유·현금·평단·평가손익 = 지금 상태 진실원천) + 매 체결은 날짜별 이벤트 로그 append. 계획서(항목 7)와 상태 라벨로 연결.
  - **초기 자본(Q21)**: 100만원.
  - **긴급 위원회(E4)**: 시뮬 엔진이 정량 임계(종목 급락·손절가 도달·지수 급변)로 **자동 발동**(무인, 임계값=튜닝 상수). 축약 3~4인(리스크·기술·수급, 정규 부분집합 페르소나 재사용). 결정은 **즉시 시장가 체결**(그 분 현재가 기준, 관통 대기 없음) + 포트폴리오·계획서 즉시 반영 + 긴급 회의록 append('긴급' 표기).
- 제외:
  - 정규 위원회·계획 수립(항목 7). 긴급위 페르소나는 항목 7 페르소나 컨텍스트 재사용.
  - 장중 실행 트리거(9시 기동)는 항목 10.

## 구현 단계
1. KRX 호가단위 스크립트(가격대별 틱, market-glossary 항목 4와 정합).
2. 1분 폴링 루프 + 한 틱 관통 지정가 체결 판정.
3. 포트폴리오 상태 제자리 갱신 + 체결 로그 append(record-conventions 항목 4 정합).
4. 긴급위 자동 발동 임계·축약 소집·즉시 시장가 체결·계획서/포트폴리오 즉시 반영·긴급 회의록.
