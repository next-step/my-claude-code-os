# 루프 오케스트레이션 (헤르메스 에이전트 체이닝)

## 목표
독립 스킬들(수집·위원회·시뮬·회고)을 시각·완료 이벤트에 맞춰 무인으로 순차 연쇄시킨다.
끝나면 사람 개입 없이 하루 루프가 굴러가고, 전체 컨텍스트 연결이 정적 검증을 통과한다.

## 범위
- 포함:
  - **완전 무인 연쇄(A4·Q6)**: 외부 '헤르메스 에이전트'가 스킬을 순차 체이닝 — 8시 뉴스 수집 실행 → 완료되면 위원회 소집 → 계획 갱신 → 09:00~15:30 시뮬 기동. 클로드 코드 내부 cron이 아니라 외부 에이전트가 시각·완료 이벤트로 트리거(S2 "스케줄러"의 실체).
  - **주간 트리거(F)**: 매주 토요일 회고 스킬 자동 실행(주간 버전 체이닝).
  - **check_context 최종 마감**: 새 스킬(항목 5~9)이 존재하게 됐으므로, 컨텍스트 소비자 링크를 새 스킬로 완성하고 정적 검증(check_context.py) 통과 확인.
  - **CLAUDE.md 컨텍스트 안내 문단 마감**: 항목 2에서 미뤄둔 CLAUDE.md '컨텍스트 자동 주입' 안내 문단의 `.claude/context/` 파일 목록을, 항목 3(retro-lessons 삭제)·항목 4(새 lessons 신설)로 확정된 최종 파일 집합과 재대조해 마무리한다(삭제된 파일 잔여 언급 제거, 신설 파일 반영).
- 제외:
  - 각 스킬 내부 로직(항목 5~9). 여기선 '언제·무엇을·다음에 무엇을' 연쇄만.

## 구현 단계
1. 헤르메스 에이전트 실체(외부 스케줄러/오케스트레이터) 확정 — 스킬 완료 → 다음 스킬 트리거 방법.
2. 일일 체인(8시→수집→위원회→계획→시뮬) 배선.
3. 주간 체인(토요일→회고) 배선.
4. check_context.py 소비자 링크를 새 스킬 집합으로 완성, 정적 검증 통과 확인.
5. CLAUDE.md 컨텍스트 안내 문단의 파일 목록을 최종 집합과 재대조·마감(항목 2에서 미뤄둔 부분).

## 건드릴 파일
- 헤르메스 에이전트 구성(위치·형태 구현 시 확정).
- `scripts/check_context.py` — 스킬 소비자 링크 최종 반영.
- `CLAUDE.md` — 컨텍스트 안내 문단 파일 목록 최종 마감(항목 2에서 이관).
