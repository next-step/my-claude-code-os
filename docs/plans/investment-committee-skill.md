# 투자 위원회 스킬 (B) + 페르소나 + 계획서 (D)

## 목표
7인 위원회가 공통 사실판 위에서 2단계로 토론해 시장 국면을 합의하고 투자 계획서를 작성/수정하는
스킬. 끝나면 매일 회의록(append)과 살아있는 계획서(제자리 갱신)가 남고, 페르소나 정의가
컨텍스트로 분리돼 긴급위·회고와 공유된다.

## 범위
- 포함:
  - **구성(B1)**: 7인(분석 4렌즈 + 관리 3렌즈), 메인 스킬이 의장 겸 사회자. 실존 인물 페르소나 오마주 — 기술(미너비니)·펀더멘털(버핏)·거시(달리오)·심리(코스톨라니)·회의론자(탈레브)·수급(드러켄밀러)·리스크(폴 튜더 존스).
  - **페르소나 컨텍스트 분리(I2/Q4)**: 7인 페르소나 정의를 컨텍스트 파일로 분리(정규 위원회·긴급위 부분집합·회고 축약이 공유). 페르소나는 추론 스타일·강조점만 정하고 사실·수치는 브리핑·스크립트 출처만(가드레일).
  - **입력(B2)**: 전원 동일 — 오늘 브리핑 + 투자계획서 + 시뮬 현황(공통 사실판).
  - **토론(B3)**: 2단계 순차 — 1단계 국면 합의(항목 6 국면 스크립트 사실판 위, 상승/하락/횡보 + 사이클 위치), 2단계 계획 합의. 각 단계 끝 수렴 판정(회고 메커니즘 부분 차용).
  - **회의록(B4)**: 핵심 요약 append 로그 — 국면 판단·계획 변경 결정·전문가별 핵심 주장·수렴/미해결 쟁점.
  - **국면 산출(C3)**: 스크립트 정량치 위에 서술 라벨('상승장 후반부' 등)을 위원회가 부여, 정량+서술 병기.
  - **계획서(D1·D2·D3)**: 표준 스키마 — 종목별(진입가·목표가·손절가·목표 비중·**주문 수량**·근거·상태 라벨) + 헤더(국면 전제·목표 현금 비중·총 리스크). 부분 갱신(바뀐 종목·필드만 제자리 수정), 이력은 회의록. 계획=의도만, 실제 보유·현금은 포트폴리오(항목 8)가 진실원천, 계획서는 상태 라벨(대기/진행중/완료)로 연결. **주문 수량은 위원회가 자본·비중·진입가로 정수주까지 확정**(Q25), '못 사는 종목'은 계획 단계에서 배제.
  - **전술 한도(Q15)**: 손절가·비중·기간·자본 배분·손절 폭을 위원회가 위험 허용도(중립) + 무결성 가드레일 안에서 스스로 결정(고정 상수 아님).
- 제외:
  - 체결·포트폴리오 실제 상태(항목 8). 계획서는 상태 라벨만 참조.
  - 조건부 시나리오 규칙은 계획서에 넣지 않음(급변 대응은 항목 8 긴급위, Q16).

## 구현 단계
1. 7인 페르소나 컨텍스트 파일 작성(공유 대상 명시).
2. 공통 입력 조립(브리핑·계획서·시뮬 현황) + 국면 스크립트(항목 6) 사실판 주입.
3. 2단계 순차 토론 오케스트레이션(메인 사회자, 단계별 수렴 판정).
4. 회의록 append 로그 저장(record-conventions 항목 4와 정합).
5. 계획서 스키마 확정 + 부분 갱신 로직(주문 수량 산출 포함), 상태 라벨로 포트폴리오 연결.
