# 아침 뉴스 수집 스킬 (A)

## 목표
매일 아침, 개장 전 판단을 바꾸는 사실을 수집해 '오늘의 브리핑'으로 구조화 저장하는 독립 스킬.
끝나면 이 스킬이 정성·정량 축을 모아 브리핑 1건을 append하고, 위원회가 읽을 수 있게 최근
윈도우까지 노출한다.

## 범위
- 포함:
  - **수집 범위(확장, Q4)**: 국내 경제·시장 헤드라인 + 미국장 마감(지수·반도체) + 거시 정량 스냅샷(원달러·전일 지수·업종 등락) + 보유/관심 종목 개별 뉴스 + **수급(외국인/기관 전일 매매동향)**.
  - **수집 방식(data-sources 규약)**: 정성 축(뉴스·미국장·거시 내러티브)=웹검색 서브에이전트 / 정량(전일 지수·환율·수급)=스크립트. 공시/DART 제외.
  - **가공(Q5)**: 사실 추출·중복제거해 구조화 브리핑(축별 요약 + 출처 링크)으로 저장. **원본 전문 미저장, 링크만.** 투자 해석(매수/매도)은 브리핑에 넣지 않음(사실은 수집, 해석은 위원회).
  - **수명주기(Q7)**: 매일 브리핑 1파일 append-only 영구 누적. 소비 주입은 오늘 브리핑 전문 + 최근 N영업일(기본 N=5, 튜닝 상수).
- 제외:
  - 트리거(8시 자동 실행)는 항목 10(오케스트레이션).
  - 수급 데이터 소스 실체(네이버 종목별 투자자 매매동향 우선 검토)는 구현 시 확정.

## 구현 단계
1. 정성 서브에이전트 구성(뉴스·미국장·거시 — 기존 company-news/kr-macro 재사용 여부 판단).
2. 정량 스크립트(전일 지수·환율·수급) 확정 — 재사용 스크립트 계층(항목 3 이동분) 활용.
3. 브리핑 스키마(축별 요약 + 출처 링크) 확정, record-conventions(항목 4)와 정합.
4. append-only 저장 + 최근 N일 주입 로직.

## 건드릴 파일
- `.claude/skills/<아침 수집 스킬>/` — 신설(SKILL.md + 스크립트).
- 브리핑 저장 경로(구현 시 확정) — append-only.
- 수급/지수/환율 정량 스크립트 — 신설 또는 재사용 부품 활용.
