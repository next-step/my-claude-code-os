# CLAUDE.md + 항상 로드 2종 재프레이밍

## 목표
사람이 자율 시스템에 쥔 통제 손잡이(항상 로드 2종)와 프로젝트 지침(CLAUDE.md)을 새 정체성에
맞춘다. 끝나면 CLAUDE.md에 강의·주차·로드맵 전제가 없고, investor-profile은 위험 허용도(중립)
방향타 하나로 얇아지고, trading-principles는 무결성 가드레일 + 루프 층으로 재프레이밍돼 있다.

## 범위
- 포함:
  - **CLAUDE.md**(G3·Q5): '실습 중'·'4주간 만들 OS'·주차별 계획·단계별 로드맵 전제 항목 제거. 살아있는 문서·결정 이유 기록·뼈대 우선 같은 유효 규칙은 유지. 항상 로드 @import 2종(investor-profile·trading-principles)은 이 항목이 직접 편집한다. 단, **컨텍스트 안내 문단(.claude/context/ 파일 목록 언급)의 최종 동기화는 항목 3·4·10 이후로 미룬다** — retro-lessons 삭제(항목 3)·새 lessons 신설(항목 4)·신 스킬 소비자 확정(항목 10)이 끝나야 파일 집합이 확정되므로, 여기선 강의·로드맵 잔재만 걷어내고 파일 목록 자체는 항목 10에서 마감한다.
  - **investor-profile.md**(Q15): **위험 허용도(중립)만 남긴다.** 한도가 아니라 위원회에 주는 방향타/창립 지시. 총 손실 한도·종목당 비중·투자 기간·손절 폭은 **위원회 일임**으로 이동(고정 한도 제거). 파생2(회고 주기 연동)·파생3(한도 초과 조언 요청)·산출4(정렬 기준)는 삭제. 역할 문구를 "조언의 눈높이" → "자율 분석·계획·모의 매매·회고의 판단·집행 기준"으로 재프레이밍(K).
  - **trading-principles.md**(Q8·Q13·Q15): 무결성 가드레일 유지(출처 없는 수치 금지·근거 기록·정밀수치=스크립트·실주문은 사람·튜닝은 사람 승인·표본 없는 변경 금지). 루프 층 추가: ①무인 자동화(모의는 무인, 실주문·튜닝 반영은 사람 — A4·F3) ②긴급위 즉시 시장가 체결 예외(E4·Q27). '조언/주문서 초안까지만' → '매매 판단·모의 집행까지 자율'로 재프레이밍(K). 전술 한도(손절폭 -5~8% 등)는 고정 규칙이 아니라 위원회 결정 + 회고 부활 대상으로 서술 변경(Q15).
- 제외:
  - OS.md 본문(항목 1). record-conventions·data-sources·market-glossary(항목 4).

## 구현 단계
1. CLAUDE.md에서 강의·주차·로드맵 언급 식별·제거, 유효 규칙·항상 로드 @import 2종 정리(컨텍스트 안내 문단의 파일 목록 최종 동기화는 항목 10에 위임).
2. investor-profile.md를 위험 허용도 한 항목으로 축소, 나머지 한도의 '위원회 일임 + 회고 부활' 명문화, 역할 재프레이밍.
3. trading-principles.md에 루프 층(무인 자동화·긴급위 예외) 추가, 무결성 가드레일 유지, 전술 한도 위원회 결정으로 서술 변경, '조언→판단·모의집행' 재프레이밍.
4. 세 문서 간 정체성·용어('추천' 잔재 등) 일관성 확인.

## 건드릴 파일
- `CLAUDE.md` — 강의·로드맵 언급 제거, 규칙 유지, @import 동기화.
- `.claude/context/investor-profile.md` — 위험 허용도만 남기고 축소·재프레이밍.
- `.claude/context/trading-principles.md` — 루프 층 추가·무결성 유지·재프레이밍.
