# 주간 회고 스킬 (F)

## 목표
매주 토요일, 계획을 세운 위원회 페르소나(축약)가 한 주 결과와 판단 이력을 되짚어 개선안을
도출하는 새 전용 회고 스킬. 끝나면 회고 리포트가 남고, 개선안은 사람 승인을 거쳐 시스템에
반영되는 되먹임 경로가 선다.

## 범위
- 포함:
  - **주체·메커니즘(F1)**: 새 전용 회고 스킬. 루프 위원회 페르소나(축약)가 자기 결정 되짚기, 회의론자(탈레브)가 자화자찬 견제. portfolio-retrospect의 **결정론 status 스크립트 + 수렴 토론 + 리포트 append 패턴 차용**(부품 재사용, 주체·기록은 루프 전용). 페르소나는 항목 7 컨텍스트 재사용.
  - **입력(F2)**: 결과(체결·수익률) + 판단 이력(위원회 회의록 B4·국면 판정 이력 C·계획 변경 D). '왜 그 판단을 했고 결과가 어땠나' — 실력 vs 시장 휩쓸림 분리.
  - **되먹임(F3)**: 개선안(임계·배점·손절폭·페르소나 가중) 도출은 무인, **실제 반영(스크립트 상수·docs/OS.md 변경)은 사람 승인 후.** 승인된 개선안은 상수·OS.md에 반영돼 다음 루프가 자동 적용. 표본 부족(n=0~1) 가설은 lessons 파일(항목 4)에 표본 대기로 기록. 주간 리포트를 위원회 일일 입력에 상시 주입하지 않음.
  - **트리거(설계 고정)**: 매주 토요일 자동 소집(헤르메스 체이닝 주간 버전 — 항목 10).
- 제외:
  - 튜닝 자동 반영(사람 승인 게이트 유지). 트리거 메커니즘 실체는 항목 10.

## 구현 단계
1. 결정론 status 스크립트(portfolio-retrospect evaluate 패턴 차용, 루프 기록물 대상으로 재작성).
2. 축약 위원회 페르소나 수렴 토론 오케스트레이션(회의론자 견제 포함).
3. 회고 리포트 append + 개선안 기록, 사람 승인 후 반영 경로 명문화.
4. 표본 부족 가설의 lessons 파일 기록 연결.

## 건드릴 파일
- `.claude/skills/<주간 회고 스킬>/` — 신설(SKILL.md + status 스크립트).
- 회고 리포트 저장 경로(구현 시 확정) — append-only.
- `.claude/context/<lessons>.md`(항목 4 신설분) — 표본 대기 교훈 기록.
