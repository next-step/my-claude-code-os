# A/B 동작 비교 (주입 off vs on)

## 목표
같은 입력에 대해 컨텍스트 주입 전후의 analyze-company 동작 차이가 판정 체크리스트와 함께 `docs/context-ab-test.md`에 기록돼 있다. step2 미션 필수2.

## 범위
- 포함: 수동 A/B 2회 실행 + 판정 + 기록.
- 제외: 미션이 지목한 도구(skill-creator/ab-test) 사용 — 현 환경 미설치로 기각(인터뷰 Q7). 도구를 확보하면 후속으로 도구 버전 추가 가능. 리뷰어가 도구 사용을 요구할 수 있음(알려진 위험).

## 구현 단계
1. 판정 체크리스트 정의: 손절폭이 성향의 한도를 반영하나 / 종목당 비중 조언이 등장하나 / 리포트 톤·경고가 성향(위험 허용도)에 맞나 / 기록 규약·용어 사용이 컨텍스트와 일치하나.
2. **off 실행**: 주입 지시를 임시 제거한 상태(또는 주입 연결 전 커밋 체크아웃)에서 회사 1개 분석 1회.
3. **on 실행**: 주입 연결 상태에서 같은 회사 분석 1회. 같은 날 실행해 시세 변수 고정.
4. 두 출력을 나란히 대조, 체크리스트로 판정해 `docs/context-ab-test.md`에 append-only 기록(일시·회사·양쪽 출력 요약·항목별 판정·결론).

## 건드릴 파일
- `docs/context-ab-test.md` — 신규 (결과 기록, append-only).
- (일시적) 주입 지시 off/on 전환 — 커밋하지 않는 임시 변경.
