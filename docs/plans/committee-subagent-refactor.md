# 투자 위원회 서브에이전트 전환 (동적 수렴 루프)

## 목표
현재 메인 스킬이 한 컨텍스트에서 7인 페르소나를 연기하는 investment-committee를,
**7인 전원을 페르소나당 1 서브에이전트로 분리**하고 메인이 **사회자**로서 옛
portfolio-retrospect식 **동적 수렴 토론 루프**를 돌리는 구조로 전환한다. 이 전환이 끝나면
국면→계획 2단계 각각에서 전문가 에이전트들이 수렴할 때까지(최대 5R) 라운드를 반복하고,
메인이 회의록·계획서를 남긴다.

## 범위
- 포함:
  - `.claude/agents/`에 7개 전문가 에이전트 신설(렌즈·강조점을 각 md에 직접 정의).
  - `investment-committee/SKILL.md`를 동적 수렴 루프 오케스트레이션으로 재작성.
  - `committee-personas.md`를 7인 명단·공통 규약 인덱스로 축소.
  - OS.md B 섹션 등 구조 서술을 새 아키텍처로 갱신(이유·인터뷰 ref 포함).
- 제외(후속 별도 항목):
  - 긴급위 신설(항목 8 관련) — 부분집합 스폰으로 같은 에이전트 재사용.
  - `weekly-retrospect`의 in-context 축약 위원회 → 에이전트 스폰 개정.
  - 위 둘은 에이전트를 **재사용 가능하게 설계만** 해 두고, 실제 retrofit은 각 소비자를
    건드릴 때 점진 적용(인터뷰 Q6).

## 구현 단계
1. **7 전문가 에이전트 신설** (`.claude/agents/`, 기존 리서처 3종과 같은 위치).
   - 분석 4: 기술(미너비니)·펀더멘털(버핏)·거시(달리오)·심리(코스톨라니).
   - 관리 3: 회의론자(탈레브)·수급(드러켄밀러)·리스크(폴 튜더 존스).
   - 각 md에 렌즈·강조점·경계를 직접 담고, 공통 규약(사실은 출처에서·가드레일)을 명시.
   - **입출력 계약(retrospect 채택)**: 입력=메인이 조립한 공통 사실판 + (라운드2~) 남의 직전
     입장 전문. 출력=자기 관점 주장 + 근거 수치 + `### 합의 여부`에 `AGREE`/`DISSENT:<쟁점>` 토큰.
   - **재사용 대비**: 프롬프트로 상황·모드(정규/긴급/회고 축약)를 받을 수 있게 범용 설계.
     사실·수치는 지어내지 않고 주입된 사실판·공유 컨텍스트(market-glossary 등)만 쓴다.
2. **committee-personas.md 인덱스로 축소.**
   - 7인 명단(렌즈·오마주 표)과 공통 규약(사실 출처·전술·근거 남기기)만 남긴다.
   - "이 파일을 공유하는 곳" 구조를 "정의는 각 agent .md, 이 파일은 명단·규약 인덱스"로 개정.
   - 상세 렌즈 정의는 각 agent .md로 이동했음을 명시(단일 소스·중복 방지).
3. **investment-committee/SKILL.md 재작성.**
   - 1단계 공통 입력 조립(브리핑+계획서+포트폴리오) + 2단계 market_regime.py 사실판 주입은
     유지(메인이 한 번 조립해 전원 동일 주입).
   - '위원 구성' 표·페르소나 Read 지시 → **에이전트 스폰 오케스트레이션**으로 교체.
   - **동적 수렴 루프(portfolio-retrospect 패턴)**를 국면 합의·계획 합의 **두 단계 각각**에 적용:
     - 라운드1: 관련 렌즈 전원 병렬 소집(한 응답에서 Agent 병렬 호출), AGREE/DISSENT 반환.
     - 매 라운드 후 메인 수렴 판정: (1) 전원 AGREE 또는 (2) 새 실질 반박 없음 → 종료.
     - 라운드2~5: 이의자·반응할 렌즈만 재소집, 남의 직전 입장 전문 전달.
     - 최대 5R. 미합의 시 근거 우위로 결론하되 회의론자 고수 쟁점은 "미해결 이월".
   - 국면 루프 수렴 → 그 전제 위에서 계획 루프 수렴(2단계 순차 유지, Q10).
   - 회의록 append·계획서 제자리 갱신 스키마·정합 점검(진입가>현재가 오류)은 유지.
4. **OS.md 구조 서술 갱신.**
   - B. 투자 위원회 섹션: in-context 연기 → 서브에이전트 동적 수렴 루프로 서술 갱신(이유 +
     인터뷰 ref). 긴급위·회고의 '페르소나 재사용'을 '에이전트 재사용'으로 정정.
   - 컨텍스트 분리 서술(7인 정의를 .claude/context로 분리) → 정의는 .claude/agents, personas는
     명단·규약 인덱스로 정정.
5. **검증**: verify-plan로 계획 대비 구현 확인 + 가능하면 위원회 소집 플로우를 실제로 돌려
   라운드 반복·수렴 판정·회의록/계획서 산출이 동작하는지 확인.

## 건드릴 파일
- `.claude/agents/committee-*.md` (신설 7종) — 전문가 렌즈 정의·입출력 계약.
- `.claude/skills/investment-committee/SKILL.md` — 동적 수렴 루프 오케스트레이션으로 재작성.
- `.claude/context/committee-personas.md` — 7인 명단·공통 규약 인덱스로 축소.
- `docs/OS.md` — B 섹션·긴급위·회고·컨텍스트 분리 서술 갱신.
