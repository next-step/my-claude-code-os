# 인터뷰: 투자 위원회 구현 방식 — 페르소나 연기 vs 서브에이전트 분리

## 배경
현재 investment-committee 스킬은 메인 스킬이 의장 겸 사회자로서 7인 페르소나를
한 컨텍스트 안에서 직접 연기한다(2026-07-08 daily-trading-loop Q8 확정). 이 Q8 결정을
아키텍처 관점에서 다시 열어, 전문가들을 기존 리서처 서브에이전트 3종 패턴처럼
`.claude/agents/`로 분리할지를 결정한다.

## Q1. D1 — 분리를 고려하는 근본 동기
- **결정**: 세 실질 이득을 모두 노린다 — **독립 추론 다양성**(한 컨텍스트 연기 시 렌즈가 서로
  물들어 조기 수렴하는 anchoring 방지) · **컨텍스트 격리·부하 분산**(각 전문가가 자기 관점만
  깊게, 긴 토론이 메인 컨텍스트를 오염하지 않음) · **재사용성·일관성**(긴급위·주간회고 등이
  같은 전문가 에이전트를 이름으로 재사용).
- **기각**: '실험·호기심'만 — 사용자가 세 실질 동기를 택함(호기심은 미선택).
- **이유(AI 정리·확인됨)**: 셋 다 서브에이전트 아키텍처가 실제로 주는 이득이라, 분리 방향에 무게가
  실린다. 다만 이 이득은 2단계 순차 토론의 상호 반박·수렴(Q10에서 '병렬→종합'을 기각한 이유)과
  긴장 관계이므로, 이후 D2·D4에서 그 균형을 결정한다.

## Q2. D2/D3 — 분리 범위와 단위
- **결정**: **7인 전원을 페르소나당 1 서브에이전트로 분리.** 분석 4 + 관리 3 모두 에이전트
  정의를 갖는다.
- **기각**: 분석 4렌즈만 — 재사용성 동기가 가리키는 긴급위 소집 대상(리스크·수급·회의론자=관리
  렌즈)을 에이전트로 못 만들어 재사용 이득을 관리 렌즈에서 놓친다. / 렌즈 묶음(분석군·관리군 2개)
  — 묶음 내부가 다시 한 컨텍스트 연기라 anchoring이 부분 잔존하고 개별 재사용 불가. / 현행 유지
  — D1 세 이득을 포기.
- **이유(AI 정리·확인됨)**: 독립성·재사용성을 최대로 살리는 선택. 긴급위·주간회고가 관리 렌즈를
  이름으로 재사용하려면 관리 렌즈도 에이전트여야 한다. 대가(콜드스타트 7번·수렴 복잡도)는 D4·D7에서
  다룬다.

## Q3. D4 — 토론·수렴 정합
- **결정**: **하이브리드(분석 병렬 개진 · 관리 반대신문 층).** 분석 렌즈는 독립 병렬로 1차
  개진하고, 관리 렌즈(회의론자·리스크·수급)는 그 개진을 입력으로 반대신문·게이트하는 뒤 층으로
  둔다. 독립성(분석 1차 판단)과 상호 반박(관리 검증)을 시간축으로 층 분리.
- **기각**: 2라운드 되돌림 반박 — 에이전트 간 직접 반박은 가장 충실하나 라운드마다 재스폰·비용·
  복잡도가 최대. / 1샷 병렬→메인 종합 — 가장 단순하나 Q10이 기각한 '병렬→종합'에 가까워 상호
  반박이 약함.
- **이유(AI 정리·확인됨)**: 분석은 독립 병렬이 다양성을 살리고, 관리는 본래 남의 주장을 보고 반응하는
  역할이라 뒤 층 반대신문이 자연스럽다. 2단계 순차 토론(국면→계획)의 수렴 정신을 층 구조로
  보존하면서 서브에이전트 병렬 이득을 취한다.
- **※ Q4에서 수정됨**: 사용자가 정적 하이브리드가 아니라 portfolio-retrospect식 **동적 수렴
  루프**(수렴까지 라운드 반복)를 원함이 드러나 이 결정은 Q4로 대체된다. (박제 원칙상 이 Q3 본문은
  그대로 두고, 아래 Q4가 실효 결정이다.)

## Q4. D4(수정) — 동적 수렴 토론 루프 (portfolio-retrospect 패턴 채택)
- **배경**: 사용자가 "포트폴리오 회고 스킬처럼 전문가 에이전트 위원회를 소집해 의견이 안 좁혀지면
  계속 라운드를 거듭해 토론"을 원한다고 명시. 옛 portfolio-retrospect(커밋 73adad6에서 정리,
  retro-technical/fundamental/macro/skeptic 4 에이전트)의 동적 수렴 루프가 정확한 원형.
- **결정**: 그 패턴을 그대로 채택한다.
  - **메인 = 사회자.** 서브에이전트끼리 직접 대화 못 하니 메인이 라운드로 중재·수렴 판정·기록.
  - **라운드1**: 관련 렌즈 전원을 병렬 소집(한 응답에서 Agent 병렬 호출), 각자 공통 사실판 위에서
    개회 입장을 내고 `AGREE` / `DISSENT:<쟁점>` 토큰을 반환.
  - **수렴 판정(매 라운드 후 메인)**: (1) 전원 AGREE **또는** (2) 직전 대비 새 실질 반박 없음 →
    수렴 종료. 아니면 다음 라운드.
  - **라운드2~N**: 직전 DISSENT했거나 반응할 게 있는 렌즈만 재소집하고, 다른 렌즈의 직전 입장
    전문을 함께 넘겨 반박/수정하게 한다(비용 절약).
  - **미합의 종료**: 상한까지 미합의면 메인이 근거 우위로 결론하되, 회의론자(탈레브)가 끝까지
    고수한 쟁점은 억지 합의시키지 말고 "미해결 이월"로 회의록에 남긴다(과적합 방지).
- **기각**: Q3 정적 하이브리드(분석 병렬→관리 반대신문 1회) — 상호 반박이 라운드로 이어지지 않아
  사용자가 원한 "수렴까지 토론"에 못 미친다. / 페르소나 in-context 연기(현행) — D1 독립성·재사용성
  포기.
- **이유(사용자 원문)**: "기존에 있었던 포트폴리오 회고 스킬과 유사하게 전문가 에이전트로 구성된
  위원회를 소집해서 의견이 좁혀지지 않으면 계속 라운드를 거듭해 토론을 이어나가게 만들고 싶어"

## Q5. D4c/D4d — 2단계 구조 유지 + 라운드 상한
- **결정(2단계)**: **Q10의 2단계(국면→계획) 구조를 유지하고, 각 단계마다 Q4 동적 수렴 루프를
  돈다.** 국면 합의를 동적 루프로 먼저 수렴시킨 뒤, 그 국면 전제 위에서 계획 합의를 다시 동적
  루프로 수렴시킨다(루프 2번).
- **결정(상한)**: portfolio-retrospect와 동일하게 **최대 5라운드**(각 단계별). 조기 수렴 시 종료,
  5R 미합의 시 회의론자 쟁점 이월.
- **기각**: 플랫 단일 동적 토론(국면·계획 한 토론) — Q10이 경계한 '국면·계획 혼재' 혼선 위험. /
  무한 반복 — 새 반박 없음 규칙이 사실상 방어막이나 명시 상한이 무한루프·비용 안전선으로 낫다. /
  다른 상한 값 — 표본 없이 기존 검증된 5R를 바꿀 근거 없음(무결성 5).
- **이유(AI 정리·확인됨)**: 2단계는 사용자의 원래 워크플로우(국면 분석→계획 작성)와 매핑되고 국면
  전제를 먼저 못박아야 계획이 같은 전제 위에 선다(Q10 계승). 상한 5R는 검증된 기존 상수 재사용.

## Q6. D8 — 다른 소비자 파급 (재사용성)
- **결정**: **에이전트를 재사용 가능하게 설계하되, 적용은 점진.** 7인 에이전트를 범용적으로
  (프롬프트로 상황·모드 지정) 설계해 긴급위=부분집합 스폰(리스크·수급·회의론자), 주간회고=축약
  프롬프트로 같은 에이전트를 재사용할 수 있게 둔다. **단, 이번 구현 범위는 정규 위원회까지.**
  긴급위 신설·weekly-retrospect의 에이전트 스폰 개정은 별도 후속 항목으로 남긴다.
- **기각**: 지금 세 소비자 한꺼번에 전환 — 동작 중인 weekly-retrospect 재작업까지 끌어들여 범위·
  위험이 커진다(뼈대 우선/YAGNI). / 정규 위원회 전용 — D1 재사용성 동기 축소.
- **이유(AI 정리·확인됨)**: 재사용성은 '설계 의도'로 지금 확보하고(에이전트를 범용으로), 실제 retrofit은
  각 소비자를 건드릴 때 점진 적용. 이미 동작하는 스킬을 이번 인터뷰 범위로 끌어들이지 않는다.

## Q7. D9 — 페르소나 정의 위치
- **결정**: **각 전문가의 렌즈·강조점을 자기 agent .md에 직접 담고, committee-personas.md는 7인
  명단·공통 규약 인덱스로 축소.** 모든 소비자가 같은 에이전트를 스폰하므로 정의가 에이전트에
  모여도 중복이 없다(retro-* 선례와 동일).
- **기각**: committee-personas.md 진실원체 유지 + agent는 얇은 로더(personas.md Read) — 정의는 한
  곳이나 에이전트마다 로드 한 단계가 더 붙고, 어차피 에이전트가 공유 단위라 이득이 적다. /
  personas.md 유지 + agent에 요지 복제 — 중복(정의가 두 곳), 기각.
- **파급**: committee-personas.md("이 파일을 공유하는 곳" 3소비자 부분집합 구조)를 인덱스로
  개정. investment-committee SKILL.md의 '위원 구성' 및 페르소나 Read 지시를 에이전트 스폰
  구조로 재작성. `.claude/agents/`에 7개 파일 신설(기존 리서처 3종과 같은 위치).
- **이유(AI 정리·확인됨)**: 에이전트가 곧 공유 재사용 단위(Q6)이므로, 정의를 그 단위 안에 두는 것이
  단일 소스·중복 방지 둘 다 만족한다. 공통 규약(사실 출처·가드레일)만 인덱스에 남겨 7인이 참조.

## 최종 확인
2026-07-09, 사용자가 결정 요약(D1~D9)을 검토하고 확정. 핵심: 7인 전원을 페르소나당 1
서브에이전트로 분리하고, 메인 사회자가 국면→계획 2단계마다 portfolio-retrospect식 동적 수렴
루프(최대 5R, 이의자 재소집, 미합의 시 회의론자 쟁점 이월)를 돌린다. 에이전트는 재사용 가능하게
설계하되 이번 구현 범위는 정규 위원회까지. 페르소나 정의는 각 agent .md로 이동하고
committee-personas.md는 인덱스로 축소한다.

**후속(이 인터뷰 밖):**

- (더 나중) 긴급위 신설·`weekly-retrospect` 에이전트 스폰 개정 — 같은 에이전트 재사용.
