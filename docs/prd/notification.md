# PRD — notification (알림 기능)

## 문제 (왜 필요한가)
사용자는 자신의 계정에서 일어나는 중요한 이벤트(예: 다른 사람의 로그인 시도)를 인지할 방법이 없다. 특히 로그인 실패가 발생했을 때 "언제, 누가" 시도했는지 확인할 수 없다. Notion의 Inbox처럼 계정 관련 알림을 한곳에서 확인할 수 있는 창구가 필요하다.
(실시간 전달이나 이상 징후 감지·대응은 요구사항에 명시되지 않았으므로 열린 질문으로 남긴다.)

## 목표 (이 기능이 해결하는 것)
- 로그인 실패가 발생하면 "언제, 누가 시도했는지"를 알림으로 사용자에게 전달한다.
- 사용자가 자신에게 온 알림을 확인(조회)할 수 있게 한다.
- (향후 확장) 초대 승인 같은 액션형 알림을 담을 수 있는 Inbox 형태의 구조를 지향한다.

## 사용자 시나리오 (기대 동작)
1. 누군가 사용자의 계정으로 로그인을 시도했으나 실패한다.
2. 시스템이 해당 실패 이벤트에 대한 알림을 생성한다(언제, 누가 시도했는지 정보 포함).
3. 사용자는 자신의 알림 목록(Inbox)에서 이 알림을 확인한다.
4. 사용자는 단순히 내용을 확인하는 것으로 흐름을 마친다(이번 범위에서는 확인이 주 목적).

## 범위 밖 (이번에 안 하는 것)
- 사람이 명시적으로 적은 범위 밖 항목은 없음(요구사항의 "범위 밖" 항목이 비어 있음).
- 참고: "초대 승인" 등 액션형 알림은 배경에서 "추후에 필요할 수 있음"으로 언급되었으므로, 이번 범위에 포함할지는 열린 질문으로 남긴다.

## 제약 / 조건
- 사람이 명시한 제약 없음(요구사항에 "X"로 표기됨).
