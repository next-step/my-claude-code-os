## 필수 01 — 컨텍스트 파일 5개 + 자동 주입

**요구**: 컨텍스트(md) 5개 이상 작성 + OS 스킬·서브에이전트에 자동 주입되게 연결.

- ✅ **정본 5종** — `data-model` · `categories` · `status-lifecycle` · `design-principles` · `security` (`.claude/context/`)
- ✅ 🔴 **Eager 주입** — `CLAUDE.md`의 `@.claude/context/security.md`로 매 세션 상시 로드 (100% 보장)
- ✅ 🟡 **Lazy 주입** — 각 SKILL·에이전트 상단 참조 블록. `grep`로 **15개 소비자→정본 엣지** 실측
- ✅ 하이브리드 설계: "안 읽으면 사고 + 짧음" = Eager, 나머지는 필요 시 Read = Lazy


## 필수 02 — 주입 A/B 동작 비교

**요구**: *"주입됐을 때 vs 안 됐을 때 스킬 동작을 비교"* — 분류 정본 `categories.md`를 대상으로 통제 실험.

- ✅ 단일 변수 = **정본 주입 여부**. 같은 모델·같은 입력 12종, 각 arm 3회 반복 = **72 관측**
- ✅ Arm A(미주입)는 스키마 밖 라벨 **8종을 지어냄**(자격증·재정·반려동물…) → `list-view.sh` 그룹핑 파괴
- ✅ 함정 항목(강아지 산책→건강, 약속→일상)에서 A는 흔들리고 B는 정본 규칙으로 회복
- ✅ 채점은 손계산 아닌 `score.sh`가 원자료에서 재계산 — **재현·검증 가능**

### 결과 (`bash tests/ab-injection/score.sh`)

`░` = Arm A(정본 미주입) · `█` = Arm B(정본 주입)

| 지표 | Arm A | Arm B | Δ |
|------|:---:|:---:|:---:|
| **정확도** (정답 일치) | `░░░░░░░░░░` 50.0% | `███████████████████░` **97.2%** | **+47.2%p** |
| **어휘 준수** (6종 스키마) | `░░░░░░░░░░` 50.0% | `████████████████████` **100%** | +50.0%p |
| **일관성** (3회 만장일치) | `░░░░░░░░░░░` 58.3% | `██████████████████░░` **91.7%** | +33.4%p |
| **함정 항목** (#6·11·12) | `░░░░` 22.2% | `██████████████████░░` **88.9%** | +66.7%p |

> **해석**: strict 정확도 격차(**+47.2%p**)가 주입의 순효과. Arm A도 사람이 사후 동의어
> 사전(`자격증→스터디`…)을 만들면 83.3%까지 회복되지만, 그 사전을 만드는 일 자체가
> 주입이 없애주는 수작업 비용이다. 상세: [`tests/ab-injection/README.md`](../tests/ab-injection/README.md)

## 도전 01 — 주입 검증 테스트

**요구**: 컨텍스트 주입이 올바른지 확인하는 테스트 제작 (버그 방지 목적).

- ✅ `tests/inject.sh` — **9검사, `run-tests.sh` L1 게이트**에 편입
- ✅ Eager `@import` 존재·타깃 실재, **고아 정본** 탐지, 지도↔현실 **양방향 드리프트**, README 정합성
- ✅ 역할 분담: `lint.sh`는 "경로 실재", `inject.sh`는 "주입 배선에 실제로 걸렸나"
- ✅ 한계 정직 서술 — Lazy 참조는 텍스트 존재만 확인(모델 Read는 정적 검증 불가)

## 도전 02 — 최적화 + 정량 비교

**요구**: 컨텍스트 체계를 다양한 방법으로 최적화하고 정량적으로 비교.

| 최적화 | Before → After | 방법 |
|--------|:---:|------|
| sync-readme 메인 흡수 | 5,108 → 513 토큰 (**89%↓**) | 스캔을 읽기전용 서브에이전트에 위임 |
| 통합 후 총 토큰 | 82k → 42k (**반감**) | 서브에이전트 2회 열기 → 1회 통합 |
| Eager 상주 정본 예산 | 783 / 1200 토큰 | `context-budget.sh` 회귀 게이트 |

- ✅ **위임 최적화** — 큰 스캔·문서 전문을 서브에이전트 창이 흡수, 메인엔 요약만 반환
- ✅ **손익분기 인식** — `sync-test`는 grep-only라 위임 시 비용>이득 → 의도적 미적용
- ✅ **예산 게이트** — Eager 승격이 슬그머니 비대해지는 회귀를 L1에서 차단
