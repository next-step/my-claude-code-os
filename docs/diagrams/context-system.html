컨텍스트 체계 — 소스 → 주입 훅 → 소비자

코드를 편집하면 PreToolUse 훅이 "무슨 파일을 만지는가"를 보고 알맞은 컨텍스트를 자동으로 끼워 넣는다. 스킬을 안 돌리고 맨손으로 고칠 때도 규칙·도메인 지식이 따라온다. 각 소스 카드 아래에 그 카드를 쓰는 🪝 훅 · 🧩 스킬을 표시했다(같은 카드가 훅 자동주입과 스킬 Read 두 경로로 쓰이기도 한다).

흐름 코드 편집(Edit/Write)→ PreToolUse 훅 발화→ 경로 매칭→ additionalContext 주입→ AI가 규칙·도메인 지식을 앎
