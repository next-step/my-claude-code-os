# 도메인 지도

서비스 도메인별 **정체·경계·관계**를 `/domain`으로 하나씩 쌓는 얇은 색인.
본문은 각 도메인 문서가 단일 출처 — 여기엔 한 줄 요약 + 링크만 둔다(OS.md 원칙 7).

> 이 목차는 도메인 코드를 편집할 때 `inject-domain.sh` 훅이 **항상 함께 주입**하는 **라우팅표**다(계층형).
> AI는 이 목차를 보고 어느 상세 문서를 읽을지 고른다 — 그래서 상세를 다 싣지 않아도 컨텍스트가 얇게 유지된다.

- [auth (회원가입·로그인)](auth.md) — 아이디/비밀번호로 사용자를 인증하고 JWT를 발급하는 도메인 · upstream 없음 · downstream ❓미확인
