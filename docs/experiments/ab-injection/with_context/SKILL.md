# TODO 수집기

코드에 남은 미완결 표시 주석을 모아 파일·라인과 함께 목록으로 준다. 읽기 전용이다. 코드를 고치지 않는다.

## 무엇을 찾나

기본 태그: `TODO`, `FIXME`, `HACK`, `XXX`, `BUG`, `NOTE`.

- 주석 문맥에서 등장하는 것만 센다. 단어가 문자열·식별자 안에 우연히 들어간 경우는 제외한다.
- 대소문자는 구분하지 않되, 태그 뒤에 경계(`:`, 공백, 괄호 등)가 오는 형태만 잡아 오탐을 줄인다.
- 사용자가 특정 태그만(예: FIXME만) 원하면 그 범위로 좁힌다.

## 절차

1. 대상 범위를 정한다. 지시가 없으면 현재 저장소 전체를 기본으로 하되, 규모가 크면 사용자에게 범위(디렉터리·태그)를 한 번 확인한다.
2. 검색을 돌린다. ripgrep이 있으면 우선 쓴다.

   ```
   rg -n --no-heading -i -e '\b(TODO|FIXME|HACK|XXX|BUG|NOTE)\b[:( ]' \
     --glob '!**/node_modules/**' --glob '!**/.git/**' \
     --glob '!**/dist/**' --glob '!**/build/**'
   ```

   `rg`가 없으면 `grep -rnI`로 대체한다.
3. 결과에서 파일 경로, 라인 번호, 태그, 주석 내용을 뽑는다. 자동 생성물·벤더 디렉터리·바이너리는 뺀다.
4. 아래 형식으로 정리해 답한다.

## 출력 형식

먼저 한 줄 요약(총 N건, 태그별 개수), 이어 태그별 표.

```
총 12건 — TODO 7, FIXME 3, HACK 2

## TODO (7)
| 파일 | 라인 | 내용 |
|------|------|------|
| src/auth/login.ts | 42 | 만료 토큰 재발급 처리 추가 |
| ... | ... | ... |
```

- 파일 경로는 저장소 기준 상대경로로 쓴다.
- 같은 태그는 한 표에 묶고, 파일·라인 순으로 정렬한다.
- 건수가 많으면(예: 50건 초과) 태그·디렉터리별 집계를 먼저 보여주고, 전체 목록은 이어서 낸다.
- 결과가 없으면 "해당 태그의 주석 없음"이라고만 답한다. 억지로 채우지 않는다.

## 경계

- 검색·집계만 한다. 주석을 지우거나 코드를 수정하지 않는다. 정리·제거가 필요하면 사용자에게 확인받고, 실제 변경은 별도 지시로만 한다.
- 태그 목록을 임의로 늘리거나 줄이지 않는다. 바꿀 필요가 보이면 묻는다.
