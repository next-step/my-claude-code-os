# DECISIONS — 결정 원장 / 회색지대 정책

이 문서는 결정 게이트①에서 사람이 승인한 **회색지대 결정** 중, 한 작업을 넘어 **프로젝트 전체에 지속되는 일반 정책**을 누적 기록한다.
목적: 같은 결정을 매 작업마다 처음부터 다시 묻지 않도록(**에스컬레이션 억제**) 시스템에 **기억**을 부여한다.

> **state.md와의 차이**: `state.md`의 `## 확정된 설계 결정`은 *이번 작업 한정*(작업이 끝나면 그 값도 지나감)이고,
> 이 문서는 *프로젝트 누적 정책*이다. state의 결정 중 **일반화 가능한 것만** 여기로 승격한다.
> (예: "돈은 BigDecimal" → 승격. "이 퍼즐은 유일해 강제" → sudoku 한정이라 승격 안 함.)

## 소유권 · 흐름 (계약)
- **쓰기(소유): 오케스트레이터(`/os`, 그리고 게이트①을 앞당기는 `/interview`)만.** 게이트①에서 사람이 confirm/override한 결정 중 재사용 가능한 정책을 여기에 승격 기록한다.
- **읽기**:
  - **오케스트레이터** — 게이트①을 **열기 전에** 먼저 읽는다. 여기에 이미 정한 정책이 있으면 **다시 묻지 않고** 기본값으로 적용(로그만 남김).
  - **`os-developer`(2단계)** — 구현 시 활성 정책을 **준수**한다(읽기 전용).
- **폐기**: 정책이 바뀌면 새 결정을 게이트①에서 승인받아 항목을 `상태: 폐기(YYYY-MM-DD, 사유)`로 표시하고 새 항목을 추가한다. 줄을 지우지 않는다(추적성).
- 형식: `정책 — 근거 — 적용 범위 — 확정(작업/날짜) — 상태`.

## A. 공개 API 계약
- **에러는 예외로 던진다(센티넬/Null 반환 금지).** — 실패를 호출부가 놓치지 않게 — 전 모듈 — 확정: sudoku(2026-06-30) — 상태: **활성**
  - 형식·인자 오류(null, 크기 불일치, 값 범위 밖) → `IllegalArgumentException`
  - 도메인 실패(규칙 위반·해 없음 등) → **모듈 전용 예외**(`XxxException extends RuntimeException`, 재고는 `REUSE.md §2`)
- **반환값은 원본 불변(새 배열/객체 반환).** — 입력 인자를 변형하지 않아 호출부 부작용 제거 — 배열/가변 객체를 다루는 전 모듈 — 확정: sudoku(2026-06-30) — 상태: **활성**

## B. 도메인 정확성
- **금액 계산은 `BigDecimal`을 쓴다(`double`/`float` 금지).** — 이진 부동소수의 반올림 오차로 돈이 새는 것을 원천 차단 — 금액·통화를 다루는 전 모듈 — 확정: money(2026-07-15) — 상태: **활성**
- **금액 반올림 기본은 `RoundingMode.HALF_EVEN`(은행가 반올림).** — 0.5를 가까운 짝수로 반올림해 누적 통계 편향을 없앰(금융 표준) — 금액을 다루는 전 모듈 — 확정: money(2026-07-15) — 상태: **활성**
  - 통화 scale은 모듈이 정한다(일반화: 입력 `BigDecimal`의 scale 보존이 기본). 세금·영수증 등 HALF_UP이 요구되는 특수 도메인은 그 작업 `state.md`에서 override.

## C. 환경 · 빌드 (toolchain)
- **빌드 toolchain = Java 21, Gradle(Kotlin DSL).** — 로컬·CI·빌드도구 호환의 기준선(IDE가 상위 JDK여도 빌드는 21로 정렬) — 전 모듈 — 확정: sudoku(2026-06-30) — 상태: **활성**
  - 근거: `os-mapper` 환경 프리플라이트가 IDE(JDK24) vs 빌드(21) 불일치를 경고 → 계약 기준을 21로 고정.
- **외부 의존성은 최소화(순수 로직은 JDK 표준 라이브러리만).** — 빌드 단순·공급망 리스크 축소 — 순수 로직 모듈 — 확정: sudoku(2026-06-30) — 상태: **활성**
