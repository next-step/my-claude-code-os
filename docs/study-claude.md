# CLAUDE.md

이 파일은 이 저장소에서 Claude Code CLI가 실행될 때 매 대화에 자동으로 로드되는
프로젝트 규칙 파일입니다. 이 프로젝트는 "나만의 Claude Code OS"를 직접 만들어 보며
AI와의 협업 방식을 배우는 **학습용 프로젝트**입니다.

## 프로젝트 규칙

### 1. Claude OS 관련 모든 파일은 반드시 이 프로젝트 안에 만든다

- `.claude/` 하위의 설정, 명령어, 스킬, 서브에이전트, 메모 등 **OS를 구성하는 모든 산출물**은
  이 저장소 디렉터리 내부에 생성한다.
- `~/.claude/` 같은 사용자 홈 디렉터리(전역 위치)나 저장소 밖 경로에는 만들지 않는다.
  학습 결과물이 Git으로 추적되고 PR로 리뷰될 수 있어야 하기 때문이다.
- 새 파일을 만들기 전에 저장할 위치가 프로젝트 루트(`my-claude-code-os/`) 하위인지 먼저 확인한다.
- `.claude/settings.local.json` 처럼 개인 환경 전용이라 공유하면 안 되는 파일만 예외로 두며,
  이는 `.gitignore` 에 명시되어 있다.

### 2. 대화 과정에서 AI 협업을 배울 수 있도록 양질의 설명을 제공한다

- 이 프로젝트에서의 작업은 "결과물"만큼 "과정"이 중요하다. 따라서 단순히 파일만 만들지 말고,
  **왜 그렇게 했는지**를 함께 설명한다.
- 구체적으로 다음을 대화에 포함한다:
  - 무엇을 바꿀지에 대한 **계획과 이유** (요구사항을 어떻게 해석했는지 포함)
  - 선택 가능한 **대안과 트레이드오프**, 그리고 왜 지금 방식을 골랐는지
  - Claude Code의 동작 방식(예: `CLAUDE.md` 로딩, `.claude/` 구조, 설정 우선순위 등)
    중 학습에 도움이 되는 배경 지식
  - 사용자가 다음에 직접 해볼 수 있는 **후속 단계 제안**
- 설명은 장황하게 늘어놓기보다, 학습자가 스스로 응용할 수 있을 만큼 핵심을 짚어 준다.

## 참고: 이 저장소의 구조

- `CLAUDE.md` — 지금 이 파일. 프로젝트 전역 규칙.
- `.claude/` — Claude Code OS 산출물이 쌓이는 곳.
  - `.claude/settings.json` — 팀과 공유하는 프로젝트 설정 (커밋함).
  - `.claude/settings.local.json` — 개인 환경 전용 설정 (커밋하지 않음, `.gitignore` 처리).
  - `.claude/README.md` — `.claude/` 디렉터리의 용도와 앞으로 추가될 파일 설명.
- 작업은 자신의 GitHub 아이디 브랜치에서 진행하고 PR로 리뷰를 받는다 (`README.md` 참고).
