# 실험 0003 — 평가 하니스 정착 (버킷 판정 전환 + 실측 계층)

- **날짜**: 2026-08-31 ~ 2026-09-01
- **판정**: ✅ 채택 (하니스 자체 검증 3항목 모두 충족, 실측 계층 정착) — 정식 반영(push·PR)은 사용자 직접 수행
- **한 줄 요약**: 평가 하니스를 대상 저장소에 정착시키고 판정을 색 버킷 기준으로
  전환, 실측 이미지 27장을 정답지 계층으로 추가. 하니스는 0002 결과(8/8)를 재현해
  자체 검증을 통과했고, 실측 계층이 **합성 셋이 보지 못하던 실패 유형 4계열**과
  "합성 성능이 실측으로 이전되지 않는다"는 핵심 사실을 드러냈다.

> 코드 수준 상세와 재현 방법은 대상 프로젝트 저장소의 실험 노트에 있다 (기록 격리 원칙).

## 배경 · 가설

실험 0002가 합성 8케이스를 8/8로 소진해, 측정 셋에 알려진 실패가 없는 상태가
됐다. 현행 판정(기대 RGB 유클리드 거리 ≤ 60)은 색 영역별로 엄격도가 요동치는
지각 불균일 문제가 있고(knowledge/색상-추출-평가-방법.md), 합성 셋만으로는 배포
판단 근거가 부족하다.

**가설**: ① 판정을 색 버킷 매핑(무채색 우선 분기 + CIELAB 앵커 최근접)으로
전환하면 임계값 논쟁 없이 사람의 색 인식과 정렬되고, ② 실측 이미지 계층을
추가하면 합성 셋이 못 잡던 새 실패 유형이 드러난다. 로직은 건드리지 않는
**평가 인프라 실험**이므로, 성공 기준을 "통과 수 증가" 대신 (a) 기존 결과 재현,
(b) 판정 전환의 일관성 확인, (c) 실측 계층 정착으로 재정의했다.

## 시도한 것

- 대상 저장소에 평가 파이프라인 정착 (실험 브랜치 커밋 — 측정 산출물 커밋 금지의
  승인된 예외). 분기점은 채택된 0002 실험 브랜치 끝 (채택 로직을 후보로 직접
  검증하기 위한 승인된 예외).
- **13버킷 체계 v1**: 기본 색명 11개 + navy + beige. 무채색 우선 분기 후 유채색은
  CIELAB 앵커 최근접. 기대색·추출색에 동일 매핑 함수. 인접쌍 표로 relaxed(완화)
  판정을 strict와 병행 집계. 골드·실버·카키·멀티는 서비스 색상 필터 스펙 확인
  전까지 보류.
- **3중 판정 병렬 산출**: 버킷 strict / 버킷 relaxed / 레거시 거리≤60 — 과거 기록과
  비교 가능성을 유지하는 이행기 설계. ΔE00(CIEDE2000)을 진단 보조 로그로 병기.
- **합성 생성기에 최소 노이즈 규약** (채널별 가우시안 σ=2.5, seed 고정) — 0002가
  관찰한 "무노이즈 균일 배경의 퇴화 분할로 베이스라인 과대평가" 문제의 교정.
- **실측 계층**: 사용자 제공 상품 이미지 27장. 정답지는 LLM이 이미지를 보고 초안
  (primary/acceptable/모호 태그) 작성 → HTML 리뷰 페이지(이미지·추출색 스와치·제안
  라벨 대조)로 사람이 검수·확정 → 정적 라벨 파일로 고정. 모호 케이스 7장은 집계
  분리. 이미지 파일은 커밋하지 않음(경로만 등록).
- run 간 케이스별 pass/fail diff(paired 비교) 기능 포함.

## 측정

### 하니스 자체 검증 (합성 8케이스)

- **0002 로직: strict·relaxed·레거시 모두 8/8** — 실험 0002 결과 재현. 필수 기준 충족.
- 재현성: 후보별 2회 실행 결과 완전 동일 (seed 고정).
- 베이스라인: 레거시 3/8 — 과거 기록(6/8)보다 낮음. 진단 결과 노이즈 규약이
  "완전 단색 배경에서만 분리가 성립"하던 과대평가를 교정한 것. 무노이즈로는 5/8로
  과거에 근접 (남는 1케이스 차이는 합성 구성 차이로 추정, 하니스 결함 아님).
- 판정 일치표: 16건 중 불일치 1건 — 완화 판정의 인접쌍(베이지↔흰색)이 배경 오답을
  통과시키는 예고된 부작용이 확인됨. ΔE00 14.5로 지각적으로는 명백히 다른 색이라
  strict가 타당. → "배경 유사색 케이스는 strict 병행" 운용 규칙 필요.

### 실측 계층 (real-v1, 27장)

| 슬라이스 | baseline strict | 0002 strict | baseline relaxed | 0002 relaxed |
|---|---|---|---|---|
| 전체 27장 | 17/27 | 15/27 | 23/27 | 21/27 |
| 모호 제외 20장 | 13/20 | 13/20 | 18/20 | 16/20 |

- paired diff (baseline → 0002): strict 개선 1 / **퇴행 3**, relaxed 개선 0 / 퇴행 2.
- 오류 0/27, 재현성 확인 (2회 동일).
- 레거시 거리 판정·ΔE00은 실측 라벨에 기대 RGB가 없어 미적용 (버킷 정답지 체계의
  구조적 특성).

## 배운 것

1. **합성 성능은 실측으로 이전되지 않는다.** 합성 8/8인 0002 로직이 실측에선
   strict 15/27이고, paired로는 베이스라인 대비 오히려 퇴행 3건. 합성 셋 소진이
   "로직 완성"을 의미하지 않음이 데이터로 확정됐다 — 실측 계층 추가의 목적 달성.
2. **실측 실패 유형 4계열** (다음 실험의 재료):
   ① *버킷 미커버* — 민트/틸(청록) 계열이 v1 버킷에 없어 추출이 정확해도 오답
   귀속. 저명도·저채도 유채색이 무채색 분기로 흡수되는 케이스 포함.
   ② *비상품 픽셀 선택* — 모델 착용·파지 컷에서 피부·타 의류·소품 색을 추출.
   ③ *다색 경합* — 비중이 비슷한 2색이 평균화되어 저채도로 붕괴하거나, 클러스터
   선택이 로직 버전에 따라 흔들림 (0002의 실측 퇴행 3건이 모두 이 계열).
   ④ *무채색·투명 소재* — 금속·반투명은 사람도 정하기 어려움 (모호 태그로 분리).
3. **노이즈 규약이 베이스라인 과대평가를 실제로 교정했다** — 0002의 예고(측정자
   관찰)가 재현됨. 과거 절대 수치와의 단절은 의도된 것이며, 이번 run이 새 기준선.
4. **완화 판정(relaxed)은 만능이 아니다** — 인접쌍이 배경 오답을 통과시키는 부작용이
   합성·실측 양쪽에서 확인. 감지력은 strict에 있고, relaxed는 경계색 관용 용도로
   역할이 다르다. 보고는 둘 다, 해석은 케이스 성격에 따라.
5. 하니스 소결함 2건 (상대 경로 데이터셋 인자 처리, 레거시 미적용의 표기) —
   차기 하니스 갱신 시 수정 대상.
