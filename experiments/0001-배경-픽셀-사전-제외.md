# 실험 0001 — 배경 픽셀 사전 제외

- **날짜**: 2026-08-30
- **판정**: ❌ 기준 미달 (개선 0건 / 퇴행 0건) — 채택 보류
- **한 줄 요약**: 클러스터링 전에 배경 픽셀을 제거하는 시도. 개선은 없었지만
  **진짜 병목이 "배경 제거 방식"이 아니라 "배경 감지"임을 확인**했다.

> 코드 수준 상세와 재현 방법은 대상 프로젝트 저장소의 실험 노트에 있다 (기록 격리 원칙).

## 배경 · 가설

대상: 이미지 대표 색상 추출기 (k-means 기반 + 배경 추정 휴리스틱의 사후 보정).
알려진 문제는 상품 이미지의 절반 이상이 배경(주로 흰색)이라 배경색이 대표색으로
뽑히는 것.

**가설**: 배경 픽셀이 클러스터링을 지배하므로, 클러스터링 *전에* 배경 추정색과
가까운 픽셀을 제외하면 사후 보정 없이도 상품 색이 1순위로 뽑힌다.

## 시도한 것

- 배경 추정색과 색 거리가 임계값 이내인 픽셀을 클러스터링 입력에서 제외
- 안전장치: 잔여 픽셀이 5% 미만이면(거의 단색 이미지) 기존 경로로 폴백
- 기존 사후 보정은 유지, 실험 전용 브랜치에 격리

## 측정

- 합성 이미지 8장 (순수 흰 배경 / 그림자 배경 / 오프화이트 / 2색 상품 /
  파스텔 배경 / 전면 단색 / 그라데이션 배경 / 배경과 비슷한 밝은 상품)
- 기존 로직 vs 신규 로직의 추출색을 기대 색 버킷과 대조 (거리 기반 근사 판정)
- **결과: 기존 6/8 → 신규 6/8. 개선 0, 퇴행 0.**

## 배운 것

1. **사전 제외가 이길 것으로 예상한 케이스는 기존 사후 보정이 이미 잡고 있었다.**
   배경이 한 클러스터로 묶이는 한 사후 폴백으로 충분하다.
2. **둘 다 실패한 케이스(파스텔 배경, 그라데이션 배경)의 공통 원인은 배경 감지 실패.**
   현재 배경 추정은 이미지 모서리 몇 점의 색 일치에 의존하는데, 배경이 균일하지
   않거나 기준 밝기에서 살짝 벗어나면 배경 자체를 못 찾는다. 감지가 실패하면
   사전 제외든 사후 보정이든 발동조차 못 한다.
3. 개선 실험은 **병목이 어디인지부터 확정**하고 시작해야 한다. 이번엔 하류(제거
   방식)를 고쳤는데 병목은 상류(감지)였다.
