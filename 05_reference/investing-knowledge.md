## 이 파일 채우는 법 (Interview Mode)

AI에게 이렇게 요청:
> "investing-knowledge 인터뷰 시작해줘. 섹션 1부터 순서대로, AI가 초안을 제시하면 내가 이해 확인·수정할게."

각 섹션 상단에 **[Interview]** 블록이 있으면 아직 안 채워진 것.

### 데이터 신뢰도 규칙 (필수)

섹션은 두 유형으로 태깅되어 있다:

- **[개념]** — 정의·해석 프레임·통상적 구간 의미 등 **정성적 지식**.
  AI가 학습 데이터로 초안 작성 → 사용자가 확인·수정. 별도 출처 요구 없음.
- **[수치·출처 필수]** — 총보수·CAGR·MDD·역사적 통계 등 **정량적 수치**.
  AI가 학습 데이터의 값을 그대로 쓰지 않는다. 반드시 아래 절차:
  1. `05_reference/data-sources.md`의 신뢰 사이트에서 **WebFetch로 조회**
  2. 값 옆에 **출처 URL + 조회일(YYYY-MM-DD)** 표기
  3. 교차 확인 가능하면 2개 소스 이상 확인
  4. 조회 실패 시 추정 금지 — "미조회" 표기 후 넘어감

권장 1차 출처:
- ETF 상세 (총보수·AUM·추적오차): 발행사 공식 (SPDR / iShares / 삼성자산운용 / KODEX)
- 지수 통계 (CAGR·MDD·PER 밴드): S&P Global, Nasdaq, KRX, Yahoo Finance
- 매크로 (금리·VIX·DXY 역사): FRED (fred.stlouisfed.org), CBOE
- 환율 역사: 한국은행 ECOS, investing.com

## 4. 매크로 해석 가이드  `[하이브리드]`

> [Interview] 가장 중요한 섹션. AI 초안 → 사용자가 자기 기준으로 튜닝.
> 각 지표의 **구간별 의미**를 정리해서, 데일리 리포트가 자동으로 "지금이 어떤 국면인지" 말할 수 있게 함.
>
> - **구간별 의미·해석 프레임** `[개념]` → AI 초안
> - **최근 5년 궤적·역사 평균** `[수치·출처 필수]` → FRED / CBOE / 한국은행 ECOS

### 4-1. 미 국채 10년물 금리
- 구간: <3% / 3~4% / 4~5% / >5%
- 각 구간에서 성장주·가치주·채권·달러에 미치는 영향
- 최근 5년 궤적

### 4-2. VIX (변동성지수)
- 구간: <15 / 15~25 / 25~35 / >35
- 각 구간의 시장 심리 명칭 (안도/정상/공포/패닉)
- 역발상 관점: 고VIX 구간에서 적립식 매수의 역사적 결과

### 4-3. DXY (달러인덱스)
- 구간 및 신흥국 자산·미국 대형주에 미치는 영향

### 4-4. USD/KRW 환율
- 구간: <1250 / 1250~1350 / 1350~1450 / >1450
- 각 구간에서 미국 주식 신규 매수·환전·환헤지 판단
- 환차익도 과세 대상임을 상기 (→ [[tax-and-fees]])

## 사용 규칙

- 이 파일은 **판단 프레임**만 담는다. 특정 종목 매수·매도 신호는 포함하지 않는다.
- 수치·구간은 사용자 학습 상태에 맞춰 갱신 (예: "VIX 25 = 공포"는 시장 국면에 따라 변할 수 있음).
- 데일리 리포트가 이 파일의 프레임을 사용하면 리포트에 근거 문구로 표시.
